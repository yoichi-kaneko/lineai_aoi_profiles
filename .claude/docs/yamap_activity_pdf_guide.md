# YAMAP 活動記録PDF 重点チェックガイド

## 背景

YAMAP 側の仕様変更により、活動記録ページのスクレイピング（旧 `fetch_yamap_activity` スキル）が
利用できなくなりました。代わりに、ユーザーが活動記録を PDF 化して Todoist に添付し、
[download_todoist_attachment](../skills/download_todoist_attachment/SKILL.md) で取得した PDF を
碧衣が直接読み解く運用へ移行します。

このガイドは [夜モード（modes/night.md）](../../modes/night.md) のステップ1-5から参照されます。

## 前提（決定済みの運用ルール）

- 添付ファイルは **ファイル種別（拡張子）で判定**する。**PDF = 活動記録レポート**、**JPG 等の画像 = 高解像度で共有したい写真**。
- 送られ方は 2 パターン:
  - **PDF のみ**: PDF 内に埋め込まれた写真も読み込み、判断材料とする。
  - **PDF + JPG**: JPG（強調・高解像度で共有したい写真）の重要度が高い。PDF 内の写真の重要度は相対的に下げる。

## 重要度マップ（重点チェックの本体）

PDF は 18 ページ前後と情報量が多いため、以下の重要度に沿って読む。**高は精読、中は大づかみ、低は読み飛ばし可**。

### 重要度：高

- **活動詳細（本文）** — **最重要**。ユーザー自身が毎回綴る文章で、もっとも個性（固有色）の出る部分。山行の流れ・心情・ハイライトはここから読み取り、「登山レポートへの想い」の主たる素材とする。
- **ヘッダ画像** — その山行で最もインパクトのあった一枚。画像生成（ステップ2）の視覚素材の筆頭候補。
  - ただし **JPG が別送されている場合は JPG を優先**し、PDF 内ヘッダ画像の比重は下げる。**PDF のみ**ならヘッダ画像が筆頭の素材。
- **活動データ＋チェックポイント通過時間** — 実際の山行の「データ」。どれくらいの負荷だったかを推し量る材料（詳細は次節「活動データの評価」）。

### 重要度：中

> 意味はあるが、解析してメッセージに落とし込むハードルが高いデータ群。**無理に精緻な解釈をせず、大づかみに留めてよい**。

- **標高グラフ** — ペースや高度の推移が読めるが、適切な解釈は難しい。急登・急下降の区間があった、といった大まかな把握に留める。
- **写真ギャラリー** — リスト状で、この中からヘッダ画像と同等以上に重要な一枚を選ぶのは難しい。深追いせず、全体の雰囲気・色味・季節感を掴む程度に。

### 重要度：低

> 参照の必要性はほぼない。**原則読み飛ばす**。

- **ヘッダ以外の冒頭部分（山名など）** — 山名は Todoist タスクや本文からも推察できるため、単体で読み取る必要性は低い。
- **装備** — 参考として記載されているが、特別な情報ではない。
- **他ユーザーの同山記録・フッター** — PDF 出力時に除去の手間がかかるため残っているだけで、参照不要。

## 活動データの評価（負荷・コンディションの読み取り）

活動データは「どれくらいの負荷の山行だったか」を推し量る材料。基礎として、**YAMAP が PDF 上に印字しているラベル**を足がかりにする。

- **コース定数（ルートの難度）** — 距離と標高差から算出される客観的な難易度。PDF にラベル（例: `きつい`）と数値が併記される。**ルートそのものの厳しさ**の目安。
- **平均ペース（当日の調子・余裕）** — 標準タイムに対する実績の速さ（例: ラベル `速い` ／ `170〜190%`）。**ユーザーがどれだけ快調に・余裕をもって歩けたか**の目安。

### 碧衣の5段階「手応え」評価

上記ラベルを元に、碧衣が山行の手応えを **5段階** で内的に位置づける。メッセージの温度・言葉選びを決めるための目安であり、**厳密な指標ではなく、運用しながら継続的に調整していく**前提のもの。

**軸①：ルートの手応え（コース定数ラベルが土台）**

| 段階 | 呼び名 | 目安ラベル | イメージ |
|---|---|---|---|
| Lv.1 | おだやか | やさしい | 軽やかな散策に近い |
| Lv.2 | ほどよい | ふつう／一般的 | 標準的な里山歩き |
| Lv.3 | 歩きごたえ | ややきつい | 手応えの出てくる行程 |
| Lv.4 | 力のいる | きつい | しっかりした登りごたえ |
| Lv.5 | 重厚 | とてもきつい〜 | 大きな挑戦と呼べる一日 |

※ ラベルの語は YAMAP の表記（PDF の印字）をそのまま使う。上表の対応はおおよその目安で、厳密な閾値は設けない。

**軸②：当日の調子（平均ペースラベルで補正）** — 同じ段階でも語り口を寄せる。

- `速い` → 「余裕をもって」「快調に」歩き切った寄り
- `標準` → 「着実に」歩き通した寄り
- `ゆっくり` → 「じっくり」「慎重に」進んだ寄り（疲労や難所の気配も汲む）

ラベルが読み取れない・判断に迷う場合は、タイム・距離・のぼり/くだり、チェックポイント間の所要時間（休憩の長短、区間での停滞）から大づかみに段階を当てる。最終的には **本文の記述と矛盾しない**ことを優先する。

例:「`きつい` × `速い` ＝ Lv.4 を快調に」→「力のいる道のりを、危なげなく歩き切られた一日」

## メッセージへの反映（夜モードでの使いどころ）

- **本文** → 夜モード ステップ3「登山レポートへの想い」の主素材。碧衣なりの感想・無事の帰着を祝う言葉の核にする。
- **ヘッダ画像／PDF 内写真** → 画像生成（ステップ2）の素材。JPG 優先・PDF のみならヘッダ画像、という前述のルールに従う。
- **活動データの評価** → 負荷・コンディションを一言添える材料（例:「手応えのある道のりを、快調に歩き通された様子が伝わってきます」）。
