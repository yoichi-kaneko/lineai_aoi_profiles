# crop_image_region

座標を指定して画像を切り出すスキルです。**`crop_yamap_report` が自動検出に失敗したときの予備手段**として用意しています。

`crop_yamap_report` が4ブロックすべての切り出しに成功した場合、このスキルを使う必要はありません。

## 2つのモード

| モード | コマンド | 用途 |
| --- | --- | --- |
| **範囲スライス** | `slice_region.ts` | 切り出し位置が**まだ分からない**とき、範囲を帯状に分割して読み、位置を突き止める |
| **座標指定クロップ** | `crop_region.ts` | 切り出し位置が**分かっている**とき、その範囲を1枚切り出す |

縦長のレポート画像はそのまま Read すると縮小されて判読できません。そのため位置を目視で確かめるには、まず範囲スライスで帯に分ける必要があります。

## Claudeへの指示

### 手順の全体像

1. `crop_yamap_report` の出力JSONの **`debug.headingCandidates`** を確認する
2. 目的の見出しの `imageY.y0` が得られていれば、それが**切り出しの上端**。→ 手順4へ
3. 得られていなければ（候補0件）、**範囲スライス**で位置を探す
4. 下端を決める（次の見出しの `imageY.y0`、または範囲スライスで目視確認）
5. **座標指定クロップ**で切り出し、Read で内容を読む

`debug` フィールドの読み方は [crop_yamap_report](../crop_yamap_report/SKILL.md) の「診断情報」を参照してください。

### 範囲スライス

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/yamap/slice_region.ts "{入力画像パス}" "{出力プレフィックス}" [--from <y>] [--to <y>] [--step <px>]
```

- `入力画像パス`: 元画像（必須）。絶対パスまたはプロジェクトルートからの相対パス
- `出力プレフィックス`: 出力ファイル名の接頭辞（必須）。英数字・ハイフン・アンダースコアのみ
- `--from`: 開始y座標（任意）。省略時は画像の上端
- `--to`: 終了y座標（任意）。省略時は画像の下端
- `--step`: 1枚あたりの高さ（任意）。省略時は 1400px

出力は `tmp/{出力プレフィックス}_01.png`、`_02.png` … の連番です。

```json
{
  "imageSize": { "width": 1965, "height": 12164 },
  "sliceCount": 6,
  "slices": [
    { "outputPath": "{...}/tmp/probe_01.png", "top": 3950, "bottom": 5350 },
    { "outputPath": "{...}/tmp/probe_02.png", "top": 5350, "bottom": 6750 }
  ]
}
```

各スライスの `top` / `bottom` は**元画像座標**です。スライスを Read して「目的の位置はこの帯の上から3割あたり」と分かったら、`top + (bottom - top) * 0.3` で元画像の座標に換算できます。

**探索は狭い範囲から始めてください。** 画像全体をスライスすると枚数が増え、Read のコストがかさみます。`debug` から上端が分かっている場合は `--from` にその値を渡し、下方向だけを探します。

### 座標指定クロップ

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/yamap/crop_region.ts "{入力画像パス}" "{出力パス}" --top <y> --bottom <y> [--left <x>] [--right <x>]
```

- `入力画像パス`: 元画像（必須）
- `出力パス`: 出力先のファイルパス（必須）。`tmp/` 配下を推奨
- `--top` / `--bottom`: 切り出す縦範囲（**必須**・元画像座標）
- `--left` / `--right`: 切り出す横範囲（任意）。**省略時は画像の全幅**

YAMAPのレポートは全幅の縦長スクリーンショットのため、通常 `--left` / `--right` は指定しません。

```json
{
  "imageSize": { "width": 1965, "height": 12164 },
  "outputPath": "{...}/tmp/manual_detail.png",
  "crop": { "left": 0, "top": 3950, "width": 1965, "height": 2332 }
}
```

## 注意事項

- 範囲スライスの出力は **1回あたり20枚まで**です。超える場合はエラーになり、1枚も出力しません（必要な `--step` の値がエラーメッセージに示されます）。Read のコストを抑えるための制限です。
- `--step` は 200px 以上を指定してください。
- 座標が画像の範囲外の場合はエラーになります。ただし `--bottom` / `--to` が画像の高さを超える場合のみ、画像の下端まで切り出します。
- 同名の出力ファイルが存在する場合は上書きします。
