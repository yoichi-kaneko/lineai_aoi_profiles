# crop_yamap_report

YAMAPレポート（活動記録）画面のスクリーンショットは縦に非常に長く、そのままReadツールで読み取ると縮小されて文字が判読しづらくなります。
このスキルは画像をOCRで解析し、重要度の高い4ブロックを個別のPNGに切り出すことで、各ブロックを高い解像度のまま読み取れるようにします。

## 切り出されるブロック

| ブロック | 内容 |
| --- | --- |
| `header` | ページ最上部の実写ヘッダ画像（山名・タイトルを含む帯） |
| `activity_data` | 「活動データ」見出し〜「チェックポイント」直前（タイム・距離・上り/下りなど） |
| `checkpoints` | 「チェックポイント」見出し〜「活動詳細」直前（通過地点と時刻） |
| `activity_detail` | 「活動詳細」見出し〜写真一覧（または本文終端）直前（本文の感想・記録） |

※ YAMAPレポート画面のフォーマットに依存します。フォーマットが異なる画像では一部または全部のブロックの切り出しに失敗することがあります。

## 事前準備

依存パッケージはルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

- OCRには tesseract.js を使用します。初回実行時に日本語の学習データ（`jpn.traineddata`）を自動ダウンロードするため、ネットワーク接続が必要です（2回目以降はプロジェクトルートに保存されたキャッシュを使用します）。

## Claudeへの指示

YAMAPレポートのスクリーンショット画像を取得したあと（通常は `download_todoist_attachment` スキルで `tmp/` にダウンロード済み）、以下の手順で実行してください。

### 手順

1. 以下のコマンドをプロジェクトルートから実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/yamap/crop_activity_detail.ts "{入力画像パス}" "{出力プレフィックス}"
```

- `入力画像パス`: 切り出し対象のスクリーンショット画像（必須）。絶対パスまたはプロジェクトルートからの相対パスで指定する。
- `出力プレフィックス`: 出力ファイル名の接頭辞（必須）。英数字・ハイフン・アンダースコアのみ使用可（パス区切りは不可）。例: `yamap_20260716_001`

OCRと画像解析を行うため、縦長の大きな画像では実行に時間がかかることがあります。タイムアウトは長め（5分程度）に設定してください。

2. 標準出力のJSONを確認してください。切り出された画像は `tmp/{出力プレフィックス}_{ブロック名}.png` として保存されます。

```json
{
  "inputPath": "入力画像の絶対パス",
  "outputPrefix": "yamap_20260716_001",
  "imageSize": { "width": 1080, "height": 24000 },
  "ocrScale": 1.11,
  "savedPaths": ["{プロジェクトルート}/tmp/yamap_20260716_001_header.png", "..."],
  "results": [
    { "section": "header", "status": "OK", "outputPath": "...", "crop": { "left": 0, "top": 0, "width": 1080, "height": 600 } },
    { "section": "activity_data", "status": "FAILED", "reason": "「活動データ」または「チェックポイント」見出しを特定できませんでした" }
  ]
}
```

3. `results` のうち `status: "OK"` のブロックの `outputPath` をReadツールで読み取り、内容を把握してください。

4. `status: "FAILED"` のブロックはスキップし、成功したブロックの情報だけで読み取りを進めてください。失敗したブロックの情報が必要な場合は、元画像をReadツールで読み取って補完してください。

## 注意事項

- 4ブロックすべての切り出しに失敗した場合のみ、コマンドは終了コード1で失敗します。一部のみ失敗した場合は終了コード0で正常終了し、成功分だけが `savedPaths` に含まれます。
- 同名の出力ファイルが存在する場合は上書きします。
