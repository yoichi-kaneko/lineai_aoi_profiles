# embed_qr_code

ベース画像に URL の QR コードを重ねて保存するスタンドアロン CLI スクリプトです。
綴葉（scribe）モードが、生成したレポート画像へ YAMAP のレポート URL への導線を付ける際に使用します。

## 概要

- 「URL を QR コード化する」「ベース画像へ重ねる」の2工程をこのスキル1本で行います
- QR コードは**白い角丸カード**（水色の枠線付き）に載せた状態で重ねます。カードの余白が QR 規格のクワイエットゾーンを兼ねるため、下地に何が描かれていても読み取りに影響しません
- 貼り付け位置は**アンカー名**で指定します（座標・カード寸法はスクリプト側が持つ固定値）
- 合成後の画像は `tmp/` ディレクトリに `qr_embedded_{タイムスタンプ}.png` として保存します（`post_twitter` / `send_line_image` がそのまま扱えるパスです）
- ベース画像は変更しません（元ファイルは残ります）
- 外部 API を呼ばないため、環境変数の設定は不要です

## 事前準備

依存パッケージ（`qrcode` / `sharp`）はルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

## Claudeへの指示

画像に QR コードを埋め込むよう依頼されたとき、このスキルを使用してください。

### 手順

1. **コマンドの実行**: 以下をプロジェクトルートから実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/image/embed_qr.ts "{ベース画像パス}" "{URL}"
```

   - **第1引数**: ベース画像のパス（必須）。プロジェクトルートからの相対パス、またはプロジェクトルート内を指す絶対パス（`generate_gpt_image` が返す `savedPaths` をそのまま渡せます）。プロジェクトルート外や、シンボリックリンク経由で外へ出るパスは指定できません
   - **第2引数**: QR コード化する URL（必須）。`http` / `https` のみ受け付けます
   - 通常はこの2つだけで足ります。既定のアンカーは `bottom-right`、QR コードの大きさは 190px です

2. **オプション（必要な場合のみ）**

```bash
pnpm exec tsx src/image/embed_qr.ts "{ベース画像パス}" "{URL}" --anchor photo-bottom-right --size 150
```

   - `--anchor`: 貼り付け位置。既定は `bottom-right`

     | 値 | 位置 | 用途 |
     |---|---|---|
     | `bottom-right` | 画像の右下隅（レポート画像では碧衣の足元） | **既定**。情報量の少ない領域のため、通常はこれを使う |
     | `bottom-left` | 画像の左下隅 | 右下に重要な要素が来てしまった場合の逃げ場 |
     | `photo-bottom-right` | 代表写真フレームの内側右下 | 上記2つがどちらも使えない場合の最終手段（代表写真の一部を隠すため、常用しない） |

   - `--size`: QR コード本体の一辺（px）。120〜400 の整数。既定は 190

3. コマンドの出力から `savedPath` を取得し、以降の処理（SNS 投稿・LINE 送信など）ではこのパスの画像を使用してください。

4. `savedPath` を Read ツールで読み取り、**QR コードが重要な要素を隠していないか**を確認してください（碧衣・ルリの顔、代表写真の主題、差し込みテキスト）。隠していた場合は、別のアンカーを指定して1回だけやり直してください。

## 出力例

```json
{
  "basePath": "tmp/gpt_image_1750000000_1.png",
  "url": "https://yamap.com/activities/45591468",
  "anchor": "bottom-right",
  "qrSize": 190,
  "cardSize": 218,
  "baseSize": "1536x1024",
  "position": { "left": 1290, "top": 778 },
  "savedPath": "/Users/xxx/lineai_aoi_profiles/tmp/qr_embedded_1750000000000.png"
}
```

## 注意事項

- **座標は固定値です**: アンカーごとの座標はベース画像の寸法に対する比率で算出しています。綴葉モードのレポート画像は `generate_gpt_image` が `1536x1024` に固定して出力するため、実質的に毎回同じ位置へ貼られます。
- **読み取り耐性**: 誤り訂正レベル `Q`・QR 本体 190px の既定値であれば、画像全体が幅 400px 程度まで縮小されても、また SNS 側で JPEG 再圧縮されても読み取れることを確認しています。既定より小さくする場合は読み取りにくくなる点に留意してください。
- **失敗時の扱い**: このスキルの失敗は、呼び元のモードにとって致命的ではありません（QR は導線の付加であり、投稿本文には別途 URL が入ります）。[aoi_constraints.md](../../rules/aoi_constraints.md) の原則どおり1回だけ再試行し、それでも失敗する場合は QR なしの元画像で処理を続行してください。
