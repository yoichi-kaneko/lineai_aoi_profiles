# fetch_yamap_activity

YAMAPの活動記録ページから山行の記録を取得するスタンドアロンCLIスクリプトです。

## 概要

指定したYAMAP活動記録ページのURLへアクセスし、
ページに埋め込まれた記録データ（Next.js の `__NEXT_DATA__` JSON）から以下を抽出して標準出力に返します。

- **概要**: タイトル・山域・都道府県・活動日（開始〜終了）・日程（日帰り／N泊N日）
- **活動データ**: タイム・距離・のぼり・くだり・コース定数（体力度ラベル付き）・標準タイム・平均ペース（ペースラベル付き）・登頂した山
- **チェックポイント**: 日ごとの合計時間・休憩時間・距離・標高差と、各地点の通過時刻・地点名・標高
- **活動詳細**: ユーザーが綴った本文の全文

数値は YAMAP の画面表示と一致するよう整形されています（距離は小数第1位、標高は整数で切り捨て）。

### 取得対象外の項目

以下はページに存在しますが、**意図的に取得しません**。

- ヘッダ画像・アップロードされた写真の一覧（枚数が多く、重要な1枚を機械的に選べないため）
- タグ（ユーザーの設定に依存し、実態と合わないことがある。例: 1泊2日の記録に「日帰り」タグが付く）
- 装備品リスト・すれ違った他ユーザー

## 対応URLフォーマット

以下のURLを受け付けます。それ以外はエラーとなります。

```
https://yamap.com/activities/{ID}
```

末尾のスラッシュ・クエリ文字列（`?ref=...` など）・フラグメントは自動的に除去されます。

## 事前準備

依存パッケージはルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

## 実行方法

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/yamap/fetch_activity.ts "https://yamap.com/activities/XXXX"
```

## 注意事項

- YAMAP側の埋め込みデータ構造（`__NEXT_DATA__` の内容）が変更された場合、予告なく動作しなくなる可能性があります
- ネットワーク接続が必要です。ブラウザによるレンダリングは行わないため Chromium は不要です
- ログイン不要で閲覧できる公開の活動記録のみ対象です
- 削除済み・非公開の活動記録は、YAMAP側のメッセージを添えたエラーで終了します
- コース定数・平均ペースが非公開の場合、その行は出力されません

## Claudeへの指示

`yamap.com/activities/` で始まるURLが渡されたとき、このスキルを使用してください。
以下のコマンドをプロジェクトルートから実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/yamap/fetch_activity.ts "{ARGUMENTS として渡された URL}"
```

ARGUMENTSとして渡されたURLをそのまま引数に使用してください。

読み取りの優先順位と、活動データから山行の手応えを評価する観点は
[yamap_activity_guide.md](../../docs/yamap_activity_guide.md) を参照してください。
