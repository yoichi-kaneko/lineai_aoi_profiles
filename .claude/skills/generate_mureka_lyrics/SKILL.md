# generate_mureka_lyrics

Mureka APIを使って歌詞を生成するスタンドアロン CLI スクリプトです。

## 概要

- プロンプトを受け取り、Mureka の歌詞生成APIで歌詞とタイトルを生成します
- 生成された歌詞とタイトルはJSON形式で出力されます

## 事前準備

依存パッケージはルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

プロジェクトルートの `.env` に以下の環境変数が必要です。

```
MUREKA_API_KEY="your_api_key"
```

## プロンプトの受け渡し方法（ファイル経由）

プロンプトは**コマンド引数で直接渡さず**、一時ファイル `tmp/mureka_lyrics_prompt.txt` に保存し、そのパスを引数で渡します。スクリプトはファイルを読み込んでプロンプトとして使用します。これにより、改行を含むプロンプトでもシェルのエスケープ事故が起きません。

> **改行の扱い**: ファイルに書いた内容（実際の改行を含む）が**そのまま**プロンプトとして使われます。`\n` への置換やクォート処理は不要です。

## 実行方法

1. プロンプトを `tmp/mureka_lyrics_prompt.txt` に保存する（Write ツールで本文をそのまま書き込む。改行はそのまま改行として書いてよい）。
2. ファイルパスを引数に渡してスクリプトを実行する。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/mureka/generate_lyrics.ts "tmp/mureka_lyrics_prompt.txt"
```

## 出力

成功時はJSON形式で以下を出力します。

```json
{
  "prompt": "入力したプロンプト",
  "title": "生成された曲タイトル",
  "lyrics": "生成された歌詞テキスト"
}
```

## Claudeへの指示

歌詞の生成が依頼されたとき、このスキルを使用してください。

### 表現に関する注意

Mureka の最適化は、下書きに込めた比喩・暗喩を直接的な描写へ引き戻したり、元の歌詞にない具体的な名詞（地名・施設名・物の名前など）を書き足したりすることがあります。プロンプトに【歌詞】ブロック（下書き）を含めて最適化を依頼する場合は、次の【表現ルール】を**そのまま**含めてください（[modes/song.md](../../../modes/song.md) ステップ4のテンプレートと同一の文言で統一しています）。

```text
【歌詞】に書かれた比喩・暗喩・抽象的な情景表現はそのまま保持し、直接的・説明的な描写へ書き換えないこと。実在の地名・施設名・製品名などの固有名詞や、具体的な物の名詞を、【歌詞】にない形で新たに追加しないこと。
```

### 表記に関する注意

日本語ベースの歌詞を生成する場合、Mureka が簡体字・中国語表現を混入させることがあります（例：「霧」が「雾」、「紅」が「红」、「奇跡」が「奇迹」になる）。これを防ぐため、プロンプトには次の【表記ルール】を**そのまま**含めてください（[modes/song.md](../../../modes/song.md) ステップ4のテンプレートと同一の文言で統一しています）。

```text
歌詞は日本語のみで生成すること（英語の単語・フレーズの混在は許容）。簡体字・繁体字といった中国語の漢字や中国語特有の表現・語彙は使用せず、漢字はすべて日本語の字体（常用漢字など）の正書法で表記すること。例：「雾」ではなく「霧」、「红」ではなく「紅」、「奇迹」ではなく「奇跡」とする。
```

### 手順

1. プロンプトを、そのまま `tmp/mureka_lyrics_prompt.txt` に保存してください（改行はそのまま改行として書き込み、`\n` への置換はしない）。保存後、Claude 自身が `tmp/mureka_lyrics_prompt.txt` を Read で読み返し、上記【表記ルール】の文言（「歌詞は日本語のみで生成すること」で始まる一文）が含まれていることを確認してください。プロンプトに【歌詞】ブロック（下書き）を含めている場合は、上記【表現ルール】の文言（「【歌詞】に書かれた比喩・暗喩」で始まる一文）も同様に確認してください。含まれていなければ追記してから次へ進みます。スクリプトはこのファイルの内容を無加工で API に送るため、この確認が両ルール混入の最終ゲートになります。

2. 以下のコマンドを実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/mureka/generate_lyrics.ts "tmp/mureka_lyrics_prompt.txt"
```

3. コマンドの出力から `title` と `lyrics` を取得してください。

4. 生成されたタイトルと歌詞をユーザーに提示してください。
