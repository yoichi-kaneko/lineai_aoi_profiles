# plot_locations

複数の緯度経度を、黒背景に白い点を描いた PNG へ変換するスタンドアロン CLI スクリプトです。
週次モード「星図」で、一週間のチェックイン地点を届けることを想定した描画部品です。

## 現在の位置づけ（先行実装）

- **スキルと描画機能を先行して実装したもので、現在このスキルを呼ぶモード・フローはありません**。碧衣の各モードの実行中に、このスキルを自発的に使わないでください。
- Swarm（Foursquare）由来の座標の利用条件（画像の保存・配信・帰属表示）は確認中です。**`get_swarm_checkins` で取得したチェックイン座標を入力にしないでください**。動作確認には、`test/fixtures/image/plot_locations/` にある架空の座標を使います。

## 概要

- 入力は `{ "lat": 数値, "lng": 数値 }` の配列を書いた JSON ファイル、出力は `tmp/` 配下の PNG ファイルです
- 画像は 640×640px の黒背景に、半径 4px の白い点を描きます。道路・地形・地名などの背景地図は描きません
- 緯度経度を Webメルカトル投影で平面に変換し、全点が収まるよう中心と縮尺を自動で決めます（北が上・東が右、縦横は共通の倍率）
- 画像の端から点の中心まで 48px の余白を取ります。ごく近い点しかない場合は、投影面で 1000m 四方より細かくは拡大しません
- 成功時は、保存した PNG のパスだけを標準出力へ1行で返します
- 外部 API を呼ばないため、環境変数の設定は不要です

## 事前準備

依存パッケージ（`sharp`）はルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

## Claudeへの指示

緯度経度の点描画を依頼されたとき、このスキルを使用してください（上記「現在の位置づけ」の制約に従うこと）。

### 手順

1. **入力ファイルの作成**: 描画する地点を、次の形式で `tmp/plot_locations.json` に保存してください（Write ツールで書き込み）。

```json
[
  { "lat": 35.0, "lng": 139.0 },
  { "lat": 35.1, "lng": 139.2 }
]
```

2. **コマンドの実行**: 以下をプロジェクトルートから実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/image/plot_locations.ts "tmp/plot_locations.json" "tmp/location_plot.png"
```

   - **第1引数**: 入力 JSON のパス（必須）。プロジェクトルートからの相対パス、またはプロジェクトルート内を指す絶対パス。プロジェクトルート外や、シンボリックリンク経由で外へ出るパスは指定できません
   - **第2引数**: 出力 PNG のパス（必須）。`tmp/` 配下で、拡張子は `.png` に限ります。同名のファイルがあれば上書きします
   - オプションはありません。画像サイズ・点の大きさ・余白はスクリプト側の固定値です

   架空の座標で動作を確かめる場合は、入力にフィクスチャを指定します。

```bash
pnpm exec tsx src/image/plot_locations.ts "test/fixtures/image/plot_locations/near_only.json" "tmp/location_plot.png"
```

   | フィクスチャ | 内容 |
   |---|---|
   | `near_only.json` | 近場の地点だけ（8件） |
   | `near_and_far.json` | 近場の地点に、遠方の地点2件が混じったもの（8件） |

3. 標準出力の1行（保存した PNG の絶対パス）を取得し、以降の処理ではこのパスの画像を使用してください。

4. 保存したパスを Read ツールで読み取り、点が描かれていることを確認してください。

### 入力の制約

次の入力はエラーになります（標準エラーへ内容を出し、終了コード1で終わります）。エラー文には何件目のどの項目かだけが示され、座標の値は含まれません。

| ケース | 扱い |
|---|---|
| 配列でない、0件、13件以上 | エラー |
| `lat` / `lng` の欠落、数値型以外（文字列の `"35.0"` を含む）、非有限値 | エラー |
| 経度が ±180° の範囲外 | エラー |
| 緯度が ±85.05112878° の範囲外（Webメルカトルで扱える範囲） | エラー。位置を黙って補正しない |
| 経度の最大値−最小値が 180° を超える（日付変更線をまたぐ） | エラー |

`lat` / `lng` 以外のプロパティは無視します。

## 出力例

```text
/Users/xxx/lineai_aoi_profiles/tmp/location_plot.png
```

## 注意事項

- **1点・同一座標**: 1点だけ、または全点が同じ座標の場合は、画像の中央に描きます。同じ地点への複数回のチェックインは同じ位置に重なり、回数によって点の大きさは変わりません。
- **密度のムラ（既知の課題）**: 全点を単一の縮尺で収めるため、遠方の地点が混じると近場の点が密集して重なります。約200km の範囲を収めると 1km の間隔は約2.7px となり、半径 4px の点は見分けられません。すべての点を見分けられることは保証していません。描く点を事前に最大12点へ絞り込み、重なる点をまとめる処理は [select_locations](../select_locations/SKILL.md) が担います（同じく先行実装）。
- **対象地域**: 日本国内での利用を主に想定しています。日付変更線・極域をまたぐ入力には対応していません。
- **位置情報の扱い**: 入力する座標は位置情報です。入力 JSON の中身を、報告本文や Firestore の記録へ転記しないでください。
