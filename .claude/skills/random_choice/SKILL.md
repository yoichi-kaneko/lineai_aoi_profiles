# random_choice

複数の選択肢の中からランダムに1件を選ぶスタンドアロン CLI スクリプトです。
通常はすべての選択肢を等確率で抽選し、`--weighted` を指定した場合は選択肢ごとの重みを考慮して抽選します。

## 概要

AIが何を選ぶか迷ったとき、これを使ってランダムな結果を選ぶためのものです。
2件以上の選択肢を引数に渡すと、その中からランダムに1件を返します。
通常モードではすべての選択肢が同じ確率で抽選されます。
重み付きモードでは、重みの比率に応じて抽選されます。重みの合計値は100でなくても構いません。

## 事前準備

依存パッケージはルートディレクトリで一元管理しています。
初回のみ、プロジェクトルートで以下を実行してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm install
```

## 実行方法

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/util/random_choice.ts <選択肢1> <選択肢2> [選択肢3 ...]
```

重み付きモード:

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/util/random_choice.ts --weighted <選択肢1>:<重み1> <選択肢2>:<重み2> [選択肢3:重み3 ...]
```

重みは0以上の整数で指定してください。重みの合計値は100でなくても構いませんが、合計は1以上にしてください。
`:` は選択肢と重みを分割するための記号です。選択肢文字列には `:` を含めないでください。

例:

```bash
pnpm exec tsx src/util/random_choice.ts ラーメン カレー うどん
```

```bash
pnpm exec tsx src/util/random_choice.ts --weighted A:70 B:30
```

## 出力

成功時はJSON形式で以下を出力します。

```json
{
  "selected": "カレー",
  "index": 1,
  "total": 3,
  "choices": ["ラーメン", "カレー", "うどん"]
}
```

重み付きモード:

```json
{
  "selected": "A",
  "index": 0,
  "total": 2,
  "choices": ["A", "B"],
  "weights": [70, 30],
  "totalWeight": 100,
  "mode": "weighted"
}
```

## Claudeへの指示

選択肢が2件以上渡されたとき、このスキルを使用してください。
特に重みや確率が明示されていない場合は、通常の等確率モードを使用してください。
ユーザーが選択肢ごとの重みや比率を指定した場合のみ、`--weighted` を使用してください。

### 手順

1. スキルを起動し、以下のコマンドを実行してください。
   選択肢にスペースが含まれる場合はクォートで囲んでください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/util/random_choice.ts {選択肢1} {選択肢2} [選択肢3 ...]
```

重み付き抽選を行う場合:

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/util/random_choice.ts --weighted {選択肢1}:{重み1} {選択肢2}:{重み2} [選択肢3:重み3 ...]
```

重みは0以上の整数で指定してください。`:` は分割用記号のため、選択肢文字列に含めないでください。

2. コマンドの出力から `selected` の値を取得してください。

3. 選択結果をユーザーに報告してください。
