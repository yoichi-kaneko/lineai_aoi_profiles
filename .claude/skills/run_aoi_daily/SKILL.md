# run_aoi_daily

対話モードの Claude 上で、`aoi.md` に定義された碧衣のデイリーモードを実行するためのスキルです。

`send_daily_line.sh` のように `claude -p` のヘッドレスモードを起動するのではなく、現在の対話セッション内で `aoi.md` を読み込み、該当する入力トリガーに従って処理を進めます。

## 概要

- **実行対象**: `aoi.md` の碧衣デイリーモード（`morning` / `noon` / `night` の3種のみ）
- **モード判定**: 実行環境の `Asia/Tokyo` 現在時刻から自動判定
- **日付**: 実行環境の `Asia/Tokyo` 現在日を使用
- **実行形態**: 対話モードの Claude 内で実行
- **ログ保存**: モード処理がすべて完了したあと、Firestore の `run_logs` コレクションに実行ログを保存する

## モード判定（Asia/Tokyo）

| 時間帯       | 標準モードキー |
| ------------ | -------------- |
| 03:00-08:59  | `morning`      |
| 12:00-13:59  | `noon`         |
| 20:00-22:59  | `night`        |

上記いずれにも該当しない時間帯では、モード処理を実行せず中断してください。

`off_mountain` / `up_mountain` / `song` はこのスキルの対象外です。呼び出さないでください。

## Claudeへの指示

1. `aoi.md` を読み込み、「モード概要」の表を確認してください。

2. 実行環境の `Asia/Tokyo` 現在時刻からデイリーモードを判定してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/firebase/determine_daily_mode.ts
```

- コマンドが成功した場合、標出力の1行が標準モードキー（`morning` / `noon` / `night`）です。
- コマンドが失敗した場合（終了コード 1）、該当モードがない時間帯です。**モード処理を実行せず**、エラー内容をユーザーに報告して中断してください。
- モードの手動指定（ARGUMENTS による上書き）は行わないでください。

3. 実行環境の日本時間で当日の日付を取得してください。

```bash
TZ='JST-9' date +%Y-%m-%d
```

4. `aoi.md` の「モード概要」に従い、標準モードキーと日付から入力トリガーを組み立ててください。

   例: `night` かつ日付が `2026-05-29` の場合は、`daily message (小夜): 2026-05-29`

5. 組み立てた入力トリガーを、この対話セッション内の実行指示として扱い、`aoi.md` の該当する実行フローに従って処理してください。

   - このスキル内から `claude` や `claude -p` を起動しないでください。
   - 各モードの詳細手順は、`aoi.md` に記載された `modes/*.md` を読み込んで確認してください。
   - LINE送信を伴うモードでは、同じ日付・同じモードを再実行する前に、二重送信にならないか注意してください。

6. 通常のモード処理内で必要に応じて `put_firestore_doc` を使用し、既存の `notes` への情報受け渡しを行ってください。

7. **上記のモード処理がすべて完了したあと**、実行ログを Firestore の `run_logs` コレクションに保存してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/firebase/put_log.ts "{date}" "{mode}"
```

- `{date}`: 手順3で取得した日付（YYYY-MM-DD）
- `{mode}`: 手順2で確定した標準モードキー（`morning` / `noon` / `night` のいずれか）

許可される `mode` の値は [src/firebase/runLogModes.ts](../../../src/firebase/runLogModes.ts) を参照してください。

コマンドが成功したら、追加したドキュメントのIDをユーザーに報告してください。モード処理の途中で失敗した場合は、ログ保存の前に失敗内容を報告してください。

## run_logs のドキュメント構造

| フィールド  | 型        | 内容                                   |
| ----------- | --------- | -------------------------------------- |
| date        | Timestamp | 実行対象日（引数の日付）               |
| mode        | string    | 実行した標準モードキー                 |
| createdAt   | Timestamp | ログ保存日時                           |
