# run_aoi_daily

対話モードの Claude 上で、`aoi.md` に定義された碧衣のデイリーモードを実行するためのスキルです。

`send_daily_line.sh` のように `claude -p` のヘッドレスモードを起動するのではなく、現在の対話セッション内で `aoi.md` を読み込み、該当する入力トリガーに従って処理を進めます。

## 概要

- **実行対象**: `aoi.md` の碧衣デイリーモード
- **既定モード**: `night`（小夜）
- **日付**: 実行環境の `Asia/Tokyo` 現在日を使用
- **実行形態**: 対話モードの Claude 内で実行
- **ログ保存**: 既存の `notes` に加えて、将来追加するFirestoreログ用コレクションにも保存する

## 使い方

モードを指定せずにこのスキルを呼び出した場合は、当日の `night`（小夜）モードを実行してください。

モードが指定された場合は、`aoi.md` の「モード概要」に記載された標準モードキーを参照し、対応する入力トリガー形式を組み立ててください。モード変換表はこのスキル内に重複して持たず、必ず `aoi.md` を正としてください。

## Claudeへの指示

1. `aoi.md` を読み込み、「モード概要」の表を確認してください。

2. ARGUMENTS から実行モードを判定してください。

   - モード指定がない場合は `night` を使用してください。
   - モード指定がある場合は、`aoi.md` の「モード概要」にある標準モードキーとして扱ってください。
   - 未定義のモードキーが指定された場合は、実行せずにユーザーへ確認してください。

3. 実行環境の日本時間で当日の日付を取得してください。

```bash
TZ='Asia/Tokyo' date +%Y-%m-%d
```

4. `aoi.md` の「モード概要」に従い、標準モードキーと日付から入力トリガーを組み立ててください。

   例: `night` かつ日付が `2026-05-29` の場合は、`daily message (小夜): 2026-05-29`

5. 組み立てた入力トリガーを、この対話セッション内の実行指示として扱い、`aoi.md` の該当する実行フローに従って処理してください。

   - このスキル内から `claude` や `claude -p` を起動しないでください。
   - 各モードの詳細手順は、`aoi.md` に記載された `modes/*.md` を読み込んで確認してください。
   - LINE送信を伴うモードでは、同じ日付・同じモードを再実行する前に、二重送信にならないか注意してください。

6. 通常のモード処理内で必要に応じて `put_firestore_doc` を使用し、既存の `notes` への情報受け渡しを行ってください。

7. 実行完了後、Firestore の新しいログ用コレクションにも実行ログを保存してください。

   そのスクリプトが追加されるまでは、このステップは未実装として扱い、実行ログ保存用スクリプトを呼び出さないでください。

## ログ保存の想定

新しいログ用コレクションには、少なくとも以下の情報を保存する想定です。

- 実行日
- 実行モード
- 入力トリガー
- 実行開始時刻
- 実行終了時刻
- 実行ステータス
- エラー概要（失敗時）

実際のコレクション名、フィールド定義、保存用CLIスクリプトのパスは、実装時にこのスキルへ追記してください。
