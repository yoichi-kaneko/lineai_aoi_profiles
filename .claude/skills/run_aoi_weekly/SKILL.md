# run_aoi_weekly

対話モードの Claude 上で、`aoi.md` に定義された **結星（ゆいぼし / weekly）モード**を実行するためのスキルです。

結星モードは、前週の一週間の申し送りとチェックイン記録を振り返り、訪問先の配置をもとにプラネタリウム装置「天縫（あまぬい）」が投影する星座の画像を生成して、ユーザー個人へ届ける週次モードです。日曜の小夜の申し送りと夜のチェックインまでを対象に含めるため、**月曜 00:00〜04:59（JST）の間だけ**実行します。

## 概要

- **実行対象**: `aoi.md` の結星モード（`modes/weekly.md`）
- **モード**: `weekly` 固定（`run_aoi_daily` のような時間帯によるモード判定は行わない）
- **実行時間帯**: 月曜 00:00〜04:59（JST）。範囲外では中断する
- **二重実行チェック**: 同じ日付の `run_logs`（`mode: weekly`）があれば中断する。実行時間帯を月曜に限るため、同じ日付の確認だけで週1回に収まる
- **日付**: 実行環境の日本標準時（JST）現在日を使用
- **実行形態**: 対話モードの Claude 内で実行
- **tmp 掃除**: 処理の最初に `refresh_tmp.sh` で `tmp/` をクリーンアップする
- **ログ保存**: モード処理がすべて完了したあと、Firestore の `run_logs` コレクションに実行ログを保存する

ヘッドレス実行の `send_daily_line.sh weekly` も、同じ実行時間帯の判定と `run_logs` の確認・記録を行います。

## Claudeへの指示

1. プロジェクトルートで `refresh_tmp.sh` を実行し、`tmp/` をクリーンアップしてください。前回実行の残骸を参照せず、処理開始時に一度だけ行います。

```bash
cd {プロジェクトルートの絶対パス}
bash refresh_tmp.sh
```

2. `aoi.md` を読み込み、「モード概要」の表で結星（`weekly`）モードの入力トリガー形式を確認してください。

3. 実行環境の日本標準時（JST）現在時刻が、結星の実行時間帯（月曜 00:00〜04:59）に当たるかを確認してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/firebase/check_weekly_window.ts
```

- コマンドが成功した場合（終了コード 0。標準出力は `weekly`）は、次の手順へ進んでください。
- コマンドが失敗した場合（終了コード 1）は、実行時間帯の外です。**モード処理を実行せず**、エラー内容をユーザーに報告して中断してください。この場合は手順8のログ保存も行いません。
- 時間帯の判定を省略・上書きして続行しないでください。

4. 実行環境の日本標準時（JST）で当日の日付を取得してください。

   注: POSIX TZ 形式の `JST-9` を使用します（一部環境で `Asia/Tokyo` が効かないため）。

```bash
TZ='JST-9' date +%Y-%m-%d
```

5. 同じ日付の結星が実行済みでないかを、`run_logs` で確認してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/firebase/has_log.ts "{date}" "weekly"
```

- `{date}`: 手順4で取得した日付（YYYY-MM-DD）
- 標準出力が `false` の場合は、次の手順へ進んでください。
- 標準出力が `true` の場合は、同じ日付の結星が実行済みです。**モード処理を実行せず**、実行済みのため中断した旨をユーザーに報告して終了してください。
- コマンドが失敗した場合（終了コードが 0 以外。タイムアウトの `124` を含む）は、実行済みかどうかを確かめられません。二重送信を避けるため、**モード処理を実行せず**、エラー内容をユーザーに報告して中断してください。

6. `aoi.md` の「モード概要」に従い、標準モードキー `weekly` と日付から入力トリガーを組み立ててください。

   例: 日付が `2026-10-05` の場合は、`daily message (結星): 2026-10-05`

7. 組み立てた入力トリガーを、この対話セッション内の実行指示として扱い、`aoi.md` の結星モードの実行フローに従って処理してください。

   - このスキル内から `claude` や `claude -p` を起動しないでください。
   - 結星モードの詳細手順は `aoi.md` の実行フローの指示に従い、`modes/weekly.md` を確認してください。
   - `aoi.md` の実行フローまたは `modes/weekly.md` の定めにより処理を行わずに終了した場合（実装中の間を含む）や、モード処理が中断した場合は、その旨をユーザーへ報告して終了してください。この場合は手順8のログ保存を行いません。

8. **上記のモード処理がすべて完了したあと**、実行ログを Firestore の `run_logs` コレクションに保存してください。

```bash
cd {プロジェクトルートの絶対パス}
pnpm exec tsx src/firebase/put_log.ts "{date}" "weekly"
```

- `{date}`: 手順4で取得した日付（YYYY-MM-DD）
- `mode` は `weekly` 固定です。

許可される `mode` の値は [src/firebase/runLogModes.ts](../../../src/firebase/runLogModes.ts) を参照してください。

コマンドが成功したら、追加したドキュメントのIDをユーザーに報告してください。書き込みがタイムアウトした場合（終了コード `124`）は結果が分からない状態のため、確認せずに再実行しないでください（[aoi_constraints.md](../../rules/aoi_constraints.md) の「タイムアウトの扱い」）。モード処理の途中で失敗・中断した場合は、ログ保存の前にその内容を報告してください。

## run_logs のドキュメント構造

| フィールド  | 型        | 内容                                   |
| ----------- | --------- | -------------------------------------- |
| date        | Timestamp | 実行対象日（引数の日付）               |
| mode        | string    | 実行した標準モードキー（`weekly`）     |
| createdAt   | Timestamp | ログ保存日時                           |
