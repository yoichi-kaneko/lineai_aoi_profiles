# Bugbot レビュー指針

## 言語

レビューコメント・指摘・説明はすべて**日本語**で書いてください。

## プロジェクト概要

LINE AIアシスタント「碧衣（あおい）」の設定・スキル管理リポジトリです。

- 朝（暁）・昼（望）・夜（小夜）の定期モード
- 登山イベント連動の特別モード（門灯＝入山・継灯＝山小屋到着・帰灯＝下山）
- 楽曲を届ける調べモード、YAMAPレポートのSNS代筆投稿（綴葉）

カレンダー確認・登山計画・日次振り返りなどを LINE に自動送信する、個人利用中心のシステムです。

主な構成:

- `aoi.md` / `modes/` / `.claude/rules/` / `assets/` … プロファイル・モード定義（Markdown）
- `.claude/skills/` … スキル定義（`SKILL.md`）
- `src/` … 外部 API クライアント等の TypeScript 実装
- `functions/` … LINE Webhook を受ける Firebase Cloud Functions
- `*.sh` … スケジュール起動・運用スクリプト

## レビュー対象外

次はレビュー不要です（ノイズになるため指摘しないでください）:

- `node_modules/**`
- `functions/dist/**`
- `tmp/**`
- `pnpm-lock.yaml`

## プロジェクト方針（全パス共通）

### 同時実行・複数回実行の防止

本プロジェクトは個人利用・スケジュール起動が中心であり、同時実行や意図しない複数回実行は運用上ほぼ起きない前提で設計しています。

原子的な実行予約、分散ロック、idempotency key、明示的な再実行フラグによるガードなど、システムとしての厳密な同時実行・重複実行防止機構の追加は求められていません（導入予定もありません）。

`run_logs` による `morning` / `noon` / `night` の実行前スキップ（ベストエフォート）以外の排他制御を提案しないでください。詳細は README.md の「二重実行防止」セクションを参照してください。

## パス別の確認ポイント

### `src/**/*.ts`

外部 API（LINE・Firestore・Todoist・OpenWeather・Twitter 等）のクライアントスクリプト群です。以下を重点的に確認してください。

- **シークレットの扱い**: API キーやトークンがハードコードされていないこと。環境変数経由で取得し、ログやエラーメッセージに漏洩しないこと。
- **API レスポンスの検証**: 外部 API のレスポンスに対する null / undefined チェックや型の整合性。想定外のレスポンス形式で実行時エラーにならないこと。

### `functions/**/*.ts`

LINE Webhook を受信する Firebase Cloud Functions です。以下を重点的に確認してください。

- **署名検証・認証**: LINE Webhook の署名検証が正しく行われ、未認証リクエストが処理されないこと。
- **入力バリデーション**: Webhook ペイロードの検証。想定外のイベントタイプやフィールド欠落に安全に対応できること。
- **ログ漏洩**: チャネルシークレット・アクセストークンやメッセージ本文などの PII が Cloud Functions のログに出力されないこと。

### `**/*.md`

碧衣（AI パーソナルアシスタント）のプロファイル定義文書です。以下を重点的に確認してください。

- **ファイル参照の整合性**: 文書間の相対リンクやファイルパス参照（`modes/`、`.claude/rules/`、スキル名等）が実在するファイル・スキルを指していること。
- **プロファイル間の矛盾**: 追加・変更されたルールが他の文書（`aoi.md`、`modes/`、`.claude/rules/` 等）の指示と矛盾しないこと。
- **キャラクター設定との整合**: 碧衣の口調（丁寧で静か、文末に「！」を使わない）や世界観（ルミナス・ログ、プライベートルーム等）と新規追加の記述が整合していること。
- **用語・表記の一貫性**: 固有名詞（碧衣、ルリ、蛍、ルミナス・ログ等）やモード名の表記ゆれがないこと。

### `**/*.sh`

- **クォート・変数展開の安全性**: 変数展開が適切にダブルクォートされ、スペースや特殊文字を含む値でも安全に動作すること。
