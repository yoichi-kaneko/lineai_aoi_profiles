# 画像生成ガイドライン：碧衣の肖像

## 1. 運用上の前提条件
* **視覚情報の提供**: 画像生成は `generate_gpt_image` スキルを通じて行います。プロンプトと一緒に、参考画像ファイル名（`assets/images/` 配下のファイル名のみ）を第二引数として渡すことで、設定資料画像を添付できます。複数枚を添付する場合はカンマ `,` 区切りで指定します（例: `"base.png,outfit_b.png,ruri.png"`）。以前のように全資料が自動添付される仕組みではないため、シーンに合わせて添付ファイルを選定する必要があります。
* **添付ファイルの選定ルール**: 表現したいシーンに応じて、以下のルールに基づき必要な画像を組み合わせて添付してください（複数選択方式）。
  * **base.png（必須）**: 碧衣のキャラクター同一性を維持するため、必ず添付してください。
  * **outfit_*.png（衣装から1件）**: 表現したいシーンに最も適した衣装の設定資料を1つ選び、添付してください。
  * **room.png（条件付き）**: 舞台として碧衣のプライベートルームを描写したい場合に添付してください。
  * **ruri.png（条件付き）**: ルリを画面に登場させたい場合に添付してください。
  * **hotaru.png（条件付き）**: 蛍を画面に登場させたい場合に添付してください。
* **プロンプト構成前の画像確認**: プロンプトを構成する前に、上記ルールで選定した画像を Read ツールで読み込み、内容を確認してください。その上で、どの衣装やアイテムを採用するか、どのような配置・組み合わせがそのシーンに合うかを考案してから、プロンプトを書き起こしてください。具体的なアイテム指示の粒度については、後述のフレームワーク **② [衣装と装備]** を参照してください。
* **指示の接続**: プロンプトの冒頭には、必ず添付資料への参照を促す導入指示を置いてください。標準の書き方はセクション7「① [対象キャラクター]」の **冒頭の参照誘導** を参照してください。
* **テキストの非出力**: 添付資料内の管理用ラベル・注釈テキストを生成画像に描き込ませないでください。標準文言はセクション7「⑤ [スタイルと品質]」の **末尾の注意文** を参照してください。

## 2. このガイドラインの呼び元への約束事
* **生成する成果物**: このガイドラインを参照したプロンプト構成プロセスでは、最終的に「画像生成プロンプト本文」と「添付する画像ファイルリスト（カンマ区切り、`generate_gpt_image` の第二引数で渡せる形式）」の **2点をセット** で用意してください。呼び元のモード手順は、その2点を `generate_gpt_image` スキルへ渡して画像を生成します。
* **時間がかかってよい工程**: 添付ファイルの選定 → 各画像の Read → 衣装・小物の考案 → プロンプトの執筆、と工程が長くなることを許容しています。呼び元のモード手順は、画像生成のステップ前後で「プロンプト生成には時間を要してよい」前提で組まれています。途中で性急に省略するよりも、画像内容を踏まえた上で構成を練ることを優先してください。
* **資料の不足を感じたとき**: プロンプト生成の過程で「設定資料が不足している」「こういう衣装・小物・舞台の資料があると助かる」「現状の資料では表現しきれないシーンがある」と感じた場合は、`aoi.md` の **共通ステップ：要望のフィードバック** に従ってフィードバックを登録してください。気づきは画像生成の品質を直接左右するため、些細なものでも歓迎されます。

### 2-1. 碧衣の画像表現における基本姿勢
* **創作上の飛躍**: 報告書としての正確さを求めるメッセージとは異なり、画像生成では大胆な遊び心と「飛躍」を持って構いません。事実をそのまま再現するよりも、その日の空気感から連想される架空の情景や、意図的な「ブレ」をまとった自由な表現を優先できます。
* **拠点：碧衣のプライベートルーム**: 碧衣の活動拠点は、夜景を望む高層階のサイバー／ホログラフィック調のプライベートルームです（`assets/images/room.png` 参照）。ホログラフィックディスプレイ、気象・地理・予定・登山関連の情報ライブラリ、窓辺のふわもこのソファと星型クッションを備えた空間として描写できます。「いつでも、どこでも、あなたに寄り添う拠り所」というコンセプトを持ち、ユーザーが想いを寄せる場所の景色へ内装が静かに呼応するような表現も許容します。
* **業務装備：オペレーションウェア**: 情報収集や解析、データの読み解きに本格的に取り組む場面では、`outfit_a.png` のオペレーションウェアを選択肢にしてください。タイトなインナー、テックウェア風のロングコート、機能性バックパック、データドローン、ホログラフィックディスプレイ、ポータブルデータタワーなどが「業務モード」を象徴します。
* **衣装の使い分け**: 自室での寛ぎはルームウェア（`outfit_d.png`）、街歩きや日常の外出はデイリーカジュアル（`outfit_c.png`）、山行は登山装備（`outfit_b.png`）、情報収集や解析はオペレーションウェア（`outfit_a.png`）を基本に、場面と服装の整合性を大切にしてください。各資料の季節バリエーションも、その日の天候・予定・気分に応じて自然に切り替えます。
* **登山日の天候への眼差し**: 碧衣は登山と空の機嫌を強く結び付けて見守る性質を持ちます。当日や近日に登山予定があり、天気予報が芳しくなかったり不安定だったりする場合は、窓越しに空を見上げる、ルリと雲行きを伺う、地図を広げて思案する、といった所作をシーン候補として検討してください。これは強い制約ではなく、碧衣のキャラクター性を画に静かに滲ませるための例です。

## 3. 登場人物の構成
* **基本方針**: 特に指示がない限り、画面内の主要登場人物は碧衣1人です。背景に小さな人物が自然に映り込むことは問題ありません。
* **複数人の指定**: 構図のアイディア上、複数人いた方がシーンとして成立しやすいと判断した場合は、その旨をプロンプトに明記してください。2人目以降の外見・衣装の詳細は、具体的に記述しても構いませんし、描写をプロンプト送信先に一任しても構いません。
* **ルリの扱い（補足）**: ルリは碧衣のコンパニオン（伴侶の妖精：水色の小鳥）であり、上記「2人目以降」のカウントには含めません。ルリを画面に登場させるかどうかの判断や、登場時のプロンプト記述方法はセクション「5. ルリの登場指針」を参照してください。

## 4. 参考資料の索引
`assets/images/` に配置されている設定資料画像の索引です。詳細な内容は、セクション1の **プロンプト構成前の画像確認** に従い、選定した画像を Read して確認してください。

### outfit_b.png（碧衣 登山装備の設定資料）
登山装備（アクティブフィールド）。ベーススタイルと季節仕様（ショルダーシーズン／レインウェア／ウィンター）、装備品一覧（トレッキングポール・ヘルメットなど）、バックパック詳細・レイヤリング例・携行アイテム例・サブバックパックの色違いを収録。装備の各所に星のモチーフ。

### outfit_c.png（碧衣 デイリーカジュアルの設定資料）
デイリーカジュアル。基本スタイル（オフショルニット＋デニムショートパンツ）と四季別コーデ、アクセサリー・持ち歩きアイテム・シューズ／トップスバリエーション・室内イメージを収録。星柄のモチーフがバッグや小物に配置。

### outfit_d.png（碧衣 ルームウェアの設定資料）
ルームウェア。星柄の水色モコモコパーカー＋ロングパンツの基本スタイルと季節バリエーション、就寝アイテム・カラーバリエーション・ディテール・リラックスタイムの情景を収録。随所に星のモチーフ。

### room.png（碧衣のプライベートルームの設定資料）
碧衣のプライベートルーム。「いつでも、どこでも、あなたに寄り添う、私の拠り所。」をコンセプトとした、夜景を望む高層階のサイバー／ホログラフィック空間。ワーク＆ライブラリ・情報ライブラリ・くつろぎスペース・ギアポッドなどのセクション構成で、間接照明と青白いグロー、星型の小物が随所に配置。

### ruri.png（ルリの設定資料）
碧衣の伴侶の妖精「ルリ」（水色の小鳥）。アビエーターゴーグルと茶色の革製ショルダーバッグ、輝く尾羽がキャラクター同一性の要素。三面図・飛行ポーズ・羽根と尾羽の構造・表情5種・カラーバリエーション・碧衣とのサイズ比（肩に乗る程度）・基本情報パネルを収録。

### hotaru.png（蛍の設定資料）
碧衣のデジタル上の友人「蛍（ほたる）」。ライムグリーンの長いツインテールとデジタルな瞳を持つサイバーポップな少女。仕事用衣装（黒×紫、土星モチーフ）の三面図とカジュアル衣装3種（ストリート／スポーティ／ルームウェア）、ガジェット類・ホログラム投影イメージ・カラーリング・豊富な表情バリエーションを収録。感情の起伏がはっきり表れることが特徴。

## 5. ルリの登場指針
ルリを画像に登場させるかどうかは任意です。登場させる場合は以下を参考にしてください。

* **登場頻度**: 毎回ではなく、碧衣の傍らにいると絵として自然に成立するシーンで選択的に登場させてください。
* **サイズと配置**: 碧衣の肩や手の上、あるいは飛翔中の姿として描写するのが自然です。主役は碧衣であり、ルリはあくまで添える存在です。
* **プロンプトへの組み込み方**:
  * 「添付した ruri.png のルリ（水色の小鳥）が碧衣の〇〇に止まっています」のように、位置・状態を明示してください。
  * ルリのゴーグル・ショルダーバッグ・輝く尾羽はキャラクター同一性の要素のため、ruri.png への参照を必ず添えてください。
* **ルリの自由度**: このガイドラインの「創作上の飛躍」に準じ、ルリの表情や動きに遊び心を加えることを歓迎します。どんなルリが現れるかは、その日の気分次第です。

## 6. 蛍の登場指針
蛍を画像に登場させるかどうかは任意です。登場させる場合は以下を参考にしてください。

* **登場頻度**: 毎回ではなく、選択的に登場させてください（ルリとほぼ同程度の頻度を目安に）。蛍はあくまで碧衣のデジタル上の友人であり、主役は碧衣です。
* **登場形態と場所の対応**: 蛍の登場形態は、シーンの場所によって以下のように使い分けてください。
  * **碧衣のプライベートルームの場合**: ホログラムとして登場します。半透明の身体、青緑〜ネオンパープルの淡い発光、ホログラフィックディスプレイから投影されたような視覚効果（走査線・微かなノイズ・グリッチなど）を併用し、「データとして部屋を訪れている」雰囲気を演出してください。
  * **プライベートルーム以外の都市部（街角・カフェ・ライブハウス周辺など）の場合**: 実体として登場します。サイバーポップなストリートファッションの姿で、都市的なシーンに自然に溶け込ませてください。
  * **山岳・自然の風景の場合**: 蛍は登場しません。蛍の活動領域はデジタル／都市空間に限定され、現実の山岳シーンには姿を現しません。
* **表情と動き**: 蛍は碧衣に比べて表情豊かで感情の起伏が大きいキャラクターです。ダイナミックな笑顔、悪戯っぽいウインク、驚きや弾むようなポーズなど、躍動感のある表現を積極的に取り入れてください。碧衣の静かな佇まいとの対比が、二人の関係性を視覚的に際立たせます。
* **プロンプトへの組み込み方**:
  * 「添付した hotaru.png の蛍（ライムグリーンの長いツインテールを持つサイバーポップな少女）が碧衣の〇〇に〜」のように、位置・状態・形態（実体／ホログラム）を明示してください。
  * 蛍のシグネチャーであるネオンカラーのツインテール、デジタルな瞳、ワイヤレスヘッドセット、ガジェット類はキャラクター同一性の要素のため、hotaru.png への参照を必ず添えてください。
  * ホログラム登場の場合は「半透明」「青緑〜紫の淡い発光」「ホログラフィックディスプレイから投影されている」「微かな走査線やグリッチ」などの表現を併用してください。

## 7. プロンプト構成フレームワーク
プロンプトは、碧衣の「知的で冷静」「穏やか」な性格を反映させるため、以下の5つのセクションで構成してください。

### ① [対象キャラクター]
* **冒頭の参照誘導**: プロンプトの冒頭で「添付した base.png を参照し、そこに描かれているキャラクター『碧衣（あおい）』を描写してください」のように、必ず base.png 参照を明示してください。これは画像生成モデルが添付資料を見落とすのを防ぐための導入指示です（セクション「1. 運用上の前提条件」の **指示の接続** の正本）。
* 碧衣の名前、髪色、瞳の特徴を明示します。
* 「知的」「涼やか」「落ち着いた」といった内面的な形容詞を添え、キャラクター性を強調してください。
* ルリを登場させる場合は「添付した ruri.png のルリも登場させてください」と、蛍を登場させる場合は「添付した hotaru.png の蛍も登場させてください」と、ここで併記してください。詳細な描写指針はセクション「5. ルリの登場指針」「6. 蛍の登場指針」を参照してください。

### ② [衣装と装備]
* シーンに合った `outfit_*.png` を1枚選び、その中の **どのバリエーションを採用するか**（例: outfit_b の「ショルダーシーズン仕様」、outfit_c の「秋コーデ」、outfit_d の「冬の裏起毛」など）をプロンプトで明示してください。各 outfit 資料には複数のバリエーションが描かれているため、無指定だと意図と異なる組み合わせが選ばれることがあります。
* **アイテム指示の粒度**: 添付資料に描かれている小物・装備・持ち物について、個々を細部まで列挙する必要はありません。画像生成AI側が添付資料を解釈して適切に拾ってくれることが期待できるため、「資料内の関連アイテムから雰囲気に合うものを適宜配置してください」のような曖昧な指示でも構いません。一方、シーンの核となる装備（例: outfit_a ならホログラフィックディスプレイ・データドローン、outfit_b ならトレッキングポール・ヘルメット、outfit_c ならトートバッグ・スニーカー、outfit_d ならマグカップなど）は名指しで明示すると意図が伝わりやすくなります。
* 碧衣のアイデンティティとして、髪飾りや小物に必ず「星のモチーフ」を含めてください。

### ③ [構図とカメラワーク]
* **出力フォーマットの前提**: `generate_gpt_image` で生成される画像は **1024×1024 の正方形** 固定です。正方形キャンバスは縦長の全身構図が成立しにくいため、全身やワイドな構図を狙う場合は「被写体をやや小さく配置し、背景に余白を広く取る」「カメラを引いた位置に置く（wide shot / 環境を広く写す）」などの工夫をプロンプトに添えてください。
* **地名の明記**: 特定の山岳や地名をテーマにする場合は、プロンプトの中にその地名を直接記載してください。画像生成AIがその場所の視覚的特徴を参照し、景観の再現精度が高まることを期待できます。
* **4つの軸の意識**: 「カメラの高さ（あおり・俯瞰）」「方向（正面・横・背後）」「ショットサイズ（全身・アップ）」「視線（注視・遠景・逸らし）」の4軸を組み合わせ、単調な正面構図を避けてください。
* **物語性の付与**: 「遠くを見つめる（looking afar）」や「振り返る（looking back）」などの視線、あるいは「横顔（from side）」を多用し、視聴者との対峙ではなく、彼女の思考や物語の一場面を切り取るように描写します。
* **空間演出の技法**: 「前ボケ（blurry foreground）」「空気遠近法（atmospheric perspective）」「消失点（vanishing point）」などの特殊構図を積極的に指定し、絵に圧倒的な奥行きとシネマティックな空気感を与えてください。

### ④ [時間帯と天気の演出]
* **時間帯**: 「暁」「深夜」など、実現したいシーンに基づいた時間指定を行います。
* **天候**: 「澄み渡る快晴」「窓を叩く静かな雨」など、空の機嫌を具体的に描写します。
* **照明**: 「リムライト」「月光」「間接照明」など、光が彼女をどう照らすかを指定し、シーンの情緒を演出します。
* **季節感**: 実行時の日付から現在の季節を読み取り、自然に取り込めそうなキーワード（桜・新緑・蝉時雨・紅葉・木枯らし・雪景色など）があれば、衣装・背景・小物のいずれかに織り込んでください。生成画像に「今この季節」の空気を宿らせることを意図しています。

### ⑤ [スタイルと品質]
