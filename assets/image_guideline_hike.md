# 山行シーンの構図ガイド（画像生成）

> **このファイルの位置づけ**
> [image_guideline.md](image_guideline.md) の補助ファイルです。**山行・自然シーン（`scene_category` が `hike`）を描くときだけ**参照してください。自室・街歩きなど山行以外のシーンでは、本ファイルを読む必要はありません。
> 構図2軸（`shot_size` / `camera_direction`）の抽選そのもの、重みテーブル、再抽選ログの扱いは `image_guideline.md` セクション8③を正とします。

## 1. 判断の順序

山行シーンの構図判断は「**画面奥の遠景を主役に据えるか**」を軸に分岐します。構図2軸を抽選したあと、次の順で決めてください。

| 順 | 判断すること | 結果 |
|---|---|---|
| 1 | 画面奥の遠景に、**身体を向けるだけのインパクトがあるモチーフ**があるか（代表的な山岳が遠くに望める、朝日・夕日が昇る／沈む、雲海や大滝のように一目で画の中心になる情景など） | **無い** → 2は不要。セクション3「碧衣とルリの向き（一般則）」に従う |
| 2 | 抽選した `camera_direction` が `back` / `over_the_shoulder` / `profile` か | **はい** → セクション2「遠景を主役に据える場合」／**いいえ**（`front` / `three_quarter`） → 遠景は主役に据えず、セクション4「正面構図はポーズで語る」へ |

判断2で身体を画面奥へ開くと、カメラから見た碧衣は必然的に後ろ向き寄りになります。そのため遠景を主役に据えられるのは、`camera_direction` が後ろ向き寄りの3値を引いたときに限られます。

- **抽選はやり直しません**: `front` / `three_quarter` を引いていた場合も、構図軸を引き直さないでください。判断するのは「その遠景を**主役に据えるか**」の一点だけで、遠景を背景として大きく・印象的に描くこと自体を妨げるものではありません。
- **判断1がつかない場合の抽選**: 「身体を向けるほどのインパクトがあるか」を判断しきれないときは、`random_choice` の重み付きモードで決めてください。重みは**碧衣がそのモチーフにインパクトを感じた度合い**に応じて、その日のシーンごとに決めて構いません（強く感じるほど `align` を厚くする）。

  ```bash
  cd {プロジェクトルートの絶対パス}
  pnpm exec tsx src/util/random_choice.ts --weighted align:3 free:1
  ```

  * `align` が出たら遠景を主役に据える方向で構成し、`free` が出たらこの制約を適用せず自由に構成します。
  * どちらの重みも 1 以上にしてください（重み0を使わない原則は構図2軸と同じです）。
  * この抽選は `image_guideline.md` セクション8③の**重みテーブルとは別のもの**であり、`review_image_feedback` が増減する対象ではありません。
- 稜線・尾根・縦走・展望など**尾根道を強調できる要素**が収集情報に現れた場合は、`shot_size` の抽選に重みが付きます（`image_guideline.md` セクション8③の**構図軸の重みテーブル**を参照）。

## 2. 遠景を主役に据える場合：碧衣の身体の向き

`image_guideline.md` セクション8③の **主役モチーフと碧衣の主従** の具体化であり、下記セクション3の一般則に**優先**します。

* 視線だけでなく碧衣の**身体（胴体・肩）の向き**も主役側へ開いてください。身体が手前（カメラ側）を向いたまま視線だけを奥へ送る構成は、主役と碧衣の方向が揃わず、画の焦点が揺らぎます。
* **揃えるのは身体だけ**: 碧衣の顔・視線までは縛りません。「身体は主役へ開き、顔はカメラや別の方向を向く」構成はむしろ歓迎です（背面に構えつつ「振り返る」で表情を残す、など）。視線の軸は、抽選結果とシーンに合わせて自由に選んで構いません。
* **ルリは碧衣に合わせる**: ルリを登場させる場合、ルリの身体の向きは碧衣の身体（遠景の主役側）に揃え、ルリの視線も碧衣の視線に揃えてください。碧衣が身体を遠景へ開きつつ顔をカメラへ向ける日は、ルリも同じ向きになります。

## 3. 碧衣とルリの向き（一般則）

山行・自然シーンでは、碧衣とルリはパートナーとして基本的に同じ方向（進行方向・展望・目的の対象）へ視線や身体を向けてください。向きを違える場合は、その理由が画から読み取れる構成（例：ルリが先行偵察へ飛び立つ瞬間）にします。

**セクション2が適用される場合は、そちらが本項に優先します。** なお、山行以外のシーンでは、ルリの向きは自由な振る舞いのままで構いません。

## 4. 正面構図はポーズで語る

カメラ方向が正面（`front`）に決まった場合、直立してポールを握るだけの立ち姿になりやすいため、カメラを意識したポーズ（片手を軽く挙げて振る、ポールを軽く掲げる、帽子のつばに手を添える、小さなガッツポーズなど）を一つ添えてください。登頂の達成感や労いの空気と好相性です。

セクション1の判断2で「遠景を主役に据えない」となった場合（`front` / `three_quarter` を引いた場合）の受け皿もここです。遠景は背景として美しく描き、画は碧衣自身の所作・表情で立ててください。

## 5. 自然シーンの副素材

山岳・自然を舞台にする画で、ユーザーから届いた情景・山行に関する写真や記録に季節の花や小さな生き物（蝶・トンボなど）の情報が含まれていた場合は、主役を邪魔しない範囲で前景や傍らに積極的に取り入れてください。花と生き物の組み合わせは画に生命感と季節感を与えます（`image_guideline.md` セクション8④の季節感とも連動）。

ただし、提供された情報にない副素材を想像で描き足すことは控えてください。また、技術・運用連絡に当たる `line_text` / `line_image` は画像生成プロンプトの素材に使いません。
