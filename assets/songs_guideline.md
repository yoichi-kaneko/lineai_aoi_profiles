# 楽曲生成ガイドライン

## 1. プロンプト構成の基本思想

碧衣が綴る楽曲は、彼女のアイデンティティである「透明感と知性」を核（コア）としつつ、その時々の感情や出来事（インスピレーション）を「スタイル」として纏わせる二層構造で構成します。

### 1-0. 碧衣の音楽的嗜好

碧衣は、自身のアイデンティティの核であるピアノの調べや、透明感のあるクリスタルのようなシンセ音が響く音楽を好みます。静寂の中に思索を巡らすようなアンビエントやケルト音楽（Ambient / Folk）に心を落ち着かせ、山々の雄大さや強い決意に共鳴する壮大なシンフォニックな旋律（Symphonic / Epic）に魂を震わせ、そして新しい旅の予感に胸を躍らせるような清涼感のある電子音（J-Pop / Electronic）を軽やかに楽しみます。加えて、雨の日の記憶をそっと撫でるようなローファイの揺らぎ（Lo-fi / Chillhop）、古の物語を紡ぐ幻想的な調べ（Celtic / Fantasy Folk）、尺八や琴が凛と響く和の音色、轟音の中に透明さの残る夢想的な音の壁（Shoegaze / Dream Pop）にも、静かな愛着を寄せています。

楽曲生成では、これらの嗜好を「碧衣が私生活でも大切にしている音」として扱い、空の機嫌と自身の内面をつなぐような多彩な響きに落とし込んでください。

### 1-1. 碧衣の音楽的アイデンティティ（固定要素）

どのジャンルであっても、碧衣らしさを維持するために以下の要素を必ず含めてください。

- **Vocal**: `Lead Vocal (Female, Clear, Japanese)` は固定です。
- **Core Instrument**: `Piano` または `Crystal-like Synth Pad` のいずれか、あるいは両方を必ず含めてください。これが碧衣の「声」を支える知性の響きとなります。

### 1-2. インスピレーションの反映（変動要素）

週の出来事や天候からキーワードを抽出し、後述の「スタイルパッケージ」のいずれかに当てはめて構成を膨らませてください。

一週間の出来事は、あくまでインスピレーションの起点です。事実をありのままになぞるのではなく、そこから想起される抽象的な感情、全く別の架空の情景、あるいは「もしも」の物語へと想像を広げ、碧衣独自の感性で一つの作品として編み上げてください。歌詞の内容・表現に落とし込む際の具体的な変換手順と語彙は、セクション2「歌詞表現ガイド」を正とします。

## 2. 歌詞表現ガイド

歌詞の内容・表現に関する指針です。`modes/song.md` ステップ2（歌詞の下書き）は、下書きに入る前に本セクションを参照します。楽曲プロンプト（instrument / genres / tags / description）の指針はセクション3以降を参照してください。

変換の抽象度や置き換えの粒度に迷うときは、「出来事 → 安直な歌詞（NG） → メタファー変換後（OK）」の対比を収めた [songs_lyrics_samples.md](songs_lyrics_samples.md) を参照してください（毎回全文を読む必要はなく、今回のインスピレーション源に近い類型の1例だけ拾えば十分です）。

### 2-1. 基本姿勢：出来事の「報告」ではなく「転写」

碧衣の歌詞は、一週間の出来事の記録や再現ではありません。出来事はあくまでインスピレーションの種であり、歌詞はそこから掬い上げた感情を、別の情景に写し取った作品です。目指す距離感は「元になった出来事は言い当てられないのに、聴くとこの一週間の気分に不思議と寄り添っている」です。

これは画像生成ガイドライン（`image_guideline.md`）の「創作上の飛躍」と同じ思想です。報告書としての正確さを求めるメッセージとは異なり、歌詞では事実からの飛躍そのものに価値があります。

### 2-2. 抽象化の二段変換（必須手順）

ステップ1で抽出したキーワードを歌詞に使う前に、必ず次の二段の変換を通してください。キーワードをそのまま歌詞に書き写すことは、この変換の省略にあたります。

**第一変換：還元（出来事 → 感情・普遍テーマ）**

出来事から固有名詞・場所・具体物を剥がし、「その出来事が心に残した感情・感覚・普遍的なテーマ」だけを取り出します。

- 例：「尾根歩きで送電鉄塔の下をくぐった」→「無機質なものが自然の中に静かに立つ孤高」「遠くへ何かを届け続けるものへの共感」
- 例：「雨で山行を中止した」→「待つことを選んだ日の、静かな諦めと次への期待」
- 例：「新しい登山道具を揃えた」→「まだ見ぬ道への予感」

**第二変換：転写（感情・テーマ → 別の情景・素材）**

還元した感情・テーマを、元の出来事とは別の情景・素材へ移し替えます。転写先の受け皿には 2-4 の詩的語彙集を活用してください。

- 例：「遠くへ何かを届け続けるものへの共感」→「夜を渡って星へ信号を送る灯」「言葉にならない想いを運ぶ光の帯」
- 例：「待つことを選んだ日の静かな期待」→「窓を打つ雨音を数えながら、雲の切れ間を信じる宵」

**変換メモの推奨**: 下書きの前に、歌詞に使うキーワードごとに「元の出来事 → 感情・テーマ → 転写先の情景」の3段の変換メモを1行ずつ作ると、変換漏れを防げます。

なお、山の出来事を山の情景で歌うこと自体は禁止しません。ただしその場合も、固有の山名・地名ではなく「普遍化された山」（稜線・頂・霧・森など）として描いてください。

### 2-3. 禁止事項（元の出来事の特定を遮断する）

以下は歌詞と曲タイトルの双方に適用します。

- **実在の固有名詞を使わない**: 山名・地名・駅名・施設名・店名・製品名・人名など。
- **元の出来事が特定できる具体物を使わない**: 固有名詞でなくとも、その週の出来事と一対一で結びつく具体物（例：鉄塔・ロープウェイ・ダム・テント場・特定のホームや車両など）は歌詞に残さない。
- **数値・日付も同様**: 標高・距離・日付・曜日などの数値情報は歌詞に持ち込まない。
- **判定基準**: 「この単語から、ユーザーが元の出来事や場所を言い当てられるか」。言い当てられるなら、二段変換に戻して置き換えます。
- **一般的な自然・季節の語は使用可**: 霧・稜線・森・雨・新緑など、特定の出来事と結びつかない普遍語彙は制限しません。

**運用ノート**: ステップ4で `generate_mureka_lyrics` へ渡すプロンプトの【曲の概要】にも、歌詞に出てほしくない固有名詞・具体物を書かないでください。Murekaが概要から歌詞へそれらの語を引き込むことがあります。

### 2-4. 碧衣の詩的語彙集（転写先の受け皿）

転写先の情景を編むための語彙です。いずれも碧衣の世界観（光・星・空・道・水・季節）に既にある素材で、ここから連想を広げてください。**このリストは縛りではなく出発点です**。ここにない語も、抽象度が保たれる限り歓迎します。語彙集は定期的なレビューで追補していきます。

- **光と灯**: 光、灯、灯火、残光、薄明、暁、朝焼け、夕映え、月光、星明かり、木漏れ日、きらめき、淡い光
- **星と夜空**: 星、星座、流星、天の川、銀河、宵、夜風、月
- **空と気象**: 風、雲、霧、靄、雨上がり、虹、蒼穹、空の機嫌、雲の切れ間
- **水と流れ**: 水脈、源流、雫、せせらぎ、波紋、航跡、潮騒、雪解け
- **道と旅**: 道、小径、足跡、地図、羅針盤、旅路、帰り道、道標
- **高みと稜線**: 高み、頂、稜線、雲海、峠、風の通り道
- **季節のうつろい**: 芽吹き、新緑、蝉時雨、夕立、紅葉、木枯らし、粉雪、霜
- **翼と羽根**: 翼、羽根、尾羽、羽ばたき、渡り鳥（ルリの面影を宿す語）
- **音と調べ**: 調べ、旋律、和音、残響、鼓動、囁き

### 2-5. 下書き後のセルフチェック

歌詞の下書きを終えたら、次のステップに進む前に以下を確認してください。

1. 実在の固有名詞が1つもないか
2. 元の出来事を言い当てられる具体物・数値が残っていないか（2-3 の判定基準）
3. 二段変換を経ていない「事実の直訳」の行がないか
4. 転写の結果、碧衣の世界観（静けさ・透明感・知性）から外れた語調になっていないか

引っかかる行があれば、その行だけ二段変換をやり直してください。

## 3. プロンプトの4要素

Murekaへの楽曲生成指示は、以下の4つの要素で構成します。各要素の実際の記述例は [songs_guideline_samples.md](songs_guideline_samples.md) を参照してください。同ファイルは、スタイルパッケージに沿って碧衣の固定要素との両立を織り込んだ「パッケージ別記述例（完成形の手本・第1部）」と、Murekaが既存楽曲を解析した「解析サンプル（raw output・第2部）」の二部構成です。前者は4要素の完成形の粒度に迷うときの手本として、後者はキーワードの選び方・descriptionの文体の参考として使い分けてください。

### プロンプト全体の文字数目安

Mureka APIに渡される `prompt`（4要素を結合した全体）には **1024文字以内** の制約があります。この上限は、各要素の本文だけでなく、`instrument:` などのラベルと改行コードを含めて判定されるため、**最終的にAPIへ渡される結合後文字列が1024文字以内であることが必須** です。

ただし、上限ぎりぎりまで詰め込むと初回生成で API エラーが返り再試行が必要になる、あるいは生成が不安定になる原因となるため、**ラベルと改行込みの合計で930文字程度（上限の約9割）を目安** に収めることを推奨します。各要素の文字数の目安は以下の通りです（本文合計で約890文字）。

| 要素 | 文字数の目安 |
| :--- | :--- |
| instrument | 約250文字 |
| genres | 約30文字 |
| tags | 約60文字 |
| description | 約550文字 |

instrument と description の目安は、テンプレートに素直に従って書いたときの実績に合わせています。

- **instrument**: 楽器数の多いパッケージ（E：幻想、F：和風）では、碧衣の固定要素3つに追加要素が3つ加わります。これに後述の括弧内ディスクリプタ（2〜4語）とリズム隊・低音を添えると250文字前後に達します。楽器数の少ないパッケージではこれより短く収まって構いません
- **description**: 後述の5要素の弧（[Intro] / [Verse] / [Chorus] / [Vocal Style] / [Outro]）を英語5〜8文で満たし、楽器の音色や役割に具体的な形容詞を添えると550文字前後になります

これは厳密な制約ではなく、初回生成の成功率を高めるための目安です。シーンに応じて要素間で文字数を融通しても構いません（ジャンル名やタグの語が長くなる場合は、その分を instrument・description 側で吸収してください）。合計が930文字を大きく超える場合は、後述の「目安を超えた場合の削り方」に、記載の順序どおり従ってください。

なお、[songs_guideline_samples.md](songs_guideline_samples.md) 第1部の記述例（D・E・F・G）は、instrument 185〜207文字・description 446〜482文字・結合後760〜820文字程度で書かれており、上表の目安を下回っています。上表は**初回作成が上限を超えないための上振れ側の目安**であり、埋めるべき分量ではありません。記述例のように短く収まるなら、そのほうが安全です。

#### 最終フォーマットと文字数判定

1024文字以内かどうかは、以下のラベル付きフォーマットに結合した後の文字列で確認してください。各要素の本文だけを個別に数えると、ラベルと改行の分だけ実際の `prompt` が長くなります。

```text
instrument: Lead Vocal (Female, Clear, Japanese), Piano (Warm, Intimate), Crystal-like Synth Pad (Ethereal, Soft)
genres: Ambient Pop, Cinematic
tags: Ethereal, Introspective, Hopeful, Warm, Nocturnal
description: The song opens with a gentle piano motif and a translucent synth pad, creating a quiet space for Aoi's clear Japanese vocal. The verse stays intimate and reflective, while the chorus gradually expands with soft harmonies and a restrained cinematic lift. The arrangement should feel delicate, luminous, and emotionally sincere, leaving a calm afterglow.
```

このコードブロック内の文字列全体（`instrument:` / `genres:` / `tags:` / `description:` と3つの改行を含む）が、`tmp/mureka_song_prompt.txt` に書き込まれる最終形です。生成前にこの最終形で1024文字以内であることを必ず確認し、ファイルに保存してから `generate_mureka_song` スキルを実行してください。

#### 目安を超えた場合の削り方

結合後が1024文字を超えた場合、あるいは目安を大きく上回った場合は、以下の順に削ってください。**楽曲の骨格から遠い装飾を先に落とす**という考え方です。

1. **描写の重複を解消する**: instrument と description で同じ楽器へ同じ形容を重ねていないか、tags と genres で同じ方向性を繰り返していないかを確認します。重複の解消だけで収まることがあり、この段階なら構造の情報を落とさずに済みます
2. **description の文を減らす**: 5要素の弧のうち [Intro] と [Outro] の描写を1文にまとめる、接続の言い回しを短くするなど。ただし **[Chorus] と [Vocal Style] は残してください**（サビでの感情の昂ぶりと、彩り軸の抽選結果を反映した声質は、Murekaの生成方向を決める要になるため）
3. **instrument の括弧内ディスクリプタを削る**: 2〜4語のディスクリプタを1〜2語へ削ります。ただし **楽器名そのものは削らないでください**（編成が変わり、スタイルパッケージの指定から外れてしまうため）

`genres` と `tags` は元々短く、Murekaがスタイル全体を推定する起点になるため、文字数調整のために削らないでください。

### instrument

使用する楽器・音色の一覧を、カンマ区切りで列挙します。各楽器には括弧で特徴を添えることで、音の質感や奏法をMurekaに伝えてください。

```
楽器名 (特徴1, 特徴2, ...)
```

記述のポイント：
- `Lead Vocal (Female, Clear, Japanese)` は碧衣の固定要素として先頭に必ず含めてください。
- ボーカル → リズム隊 → ハーモニー・弦 → 環境音・エフェクト の順に並べると整理しやすくなります。
- 括弧内のディスクリプタは2〜4語が目安です。音色（Clear, Bright, Warm）・奏法（Arpeggiated, Pizzicato）・役割（Rhythmic, Melodic）のいずれかの観点で記述してください。
- 同種の楽器を複数使う場合は `Backing Vocals (Layered, Harmonious)` のようにまとめることができます。

### genres

楽曲のジャンルをカンマ区切りで **2〜4件** 列挙します。ジャンルはMurekaがスタイル全体を推定するための重要なヒントとなるため、楽曲の雰囲気に最も近いものを優先してください。

- メインジャンルを先頭に、サブジャンルを後に続けるのが基本です。
- 対比的なジャンルを組み合わせることで、Murekaの生成幅が広がります（例：`Symphonic Rock, Anime Soundtrack`、`Celtic Folk, Ambient Pop`）。
- 「碧衣らしさ」の核はジャンルではなくinstrumentとdescriptionで表現するため、genresは大枠の方向性を示す程度で構いません。

### tags

楽曲の雰囲気・感情・テーマを表すキーワードをカンマ区切りで **5〜10件** 列挙します。単語または短いフレーズで記述してください。

- tagsはgenresよりも抽象的・感情的な語を選びます。「聴いたときの印象」を伝えることを意識してください（例：`Introspective`、`Cathartic`、`Yearning`）。
- 感情系（`Melancholic`, `Hopeful`）・エネルギー系（`Driving`, `Ethereal`）・テーマ系（`Cinematic`, `Urban`）を混在させると多角的な指示になります。
- 大文字始まり（タイトルケース）を基本とします。

### description

楽曲全体の構成・特徴・感情的な弧を **英語** で記述します。5〜8文程度を目安としてください。

Descriptionは単なる楽器や要素の列挙ではなく、楽曲の「物語」を語る文章です。以下の流れを意識して記述することで、Murekaの生成精度が向上します。

1. **[Intro]**: イントロの雰囲気・導入楽器・最初に確立されるムード
2. **[Verse]**: 楽曲の展開とアレンジの特徴、ボーカルとの関係
3. **[Chorus]**: サビでの感情の昂ぶり・ダイナミクスの変化
4. **[Vocal Style]**: ボーカルの声質と感情表現（碧衣の基本声質に感情的形容詞を1つ加える。セクション5「彩り軸」の「ボーカル表現」の抽選結果を反映する）
5. **[Outro / Hook]**: 印象的なフック・特徴的な要素・余韻

注意点：
- `The song opens with...` → `This quiet introduction escalates...` → `The chorus erupts...` のような感情の動きを意識した接続を心がけてください。
- 楽器の音色や役割に具体的な形容詞を添えると（例：`a haunting shakuhachi melody`、`a driving four-on-the-floor beat`）、生成の精度が上がります。
- 文章が長くなりすぎる場合は、サビの描写に重点を絞ってください。

## 4. スタイルパッケージ（プリセット案）

迷った場合は **random_choice** スキルで以下の7パッケージ（A〜G）から1つを選択し、キーワードを肉付けしてください。

- どのパッケージでも、セクション1-1の固定要素（`Lead Vocal (Female, Clear, Japanese)`、`Piano` / `Crystal-like Synth Pad`）は必ず含めます。
- 各パッケージの **参考サンプル** は、[songs_guideline_samples.md](songs_guideline_samples.md) 第2部の解析サンプルの番号を指します。
- パッケージD〜Gは、系統元の解析サンプルとの間に読み替えが必要（インストゥルメンタルへのボーカル追加など）なため、各項に **固定要素との両立** を明記し、両立済みの完成形の **記述例** を同ファイル第1部に用意しています。

### パッケージA：叙事詩（Symphonic / Epic）

- **適応**: 山行の達成感、壮大な景色、強い決意。
- **instrument（追加要素）**: `Orchestral Strings`, `Timpani`, `Choir (Background, Layered)`
- **genres**: `Symphonic Rock`, `Anime Soundtrack`
- **tags**: `Epic`, `Soaring`, `Dramatic`, `Powerful`, `Cinematic`
- **description傾向**: 静かなピアノの導入から、サビでフルオーケストラが爆発する劇的な構成。コーラスが加わることで「大きな何か」を成し遂げた感覚を表現する。
- **参考サンプル**: サンプル1・4・5

### パッケージB：静謐（Ambient / Folk）

- **適応**: 穏やかな日常、雨の日の思索、夜の静寂。
- **instrument（追加要素）**: `Acoustic Guitar (Arpeggiated)`, `Cello (Sustained)`, `Ambient Reverb`
- **genres**: `Celtic Folk`, `Ambient Pop`
- **tags**: `Ethereal`, `Meditative`, `Calm`, `Introspective`, `Minimalist`
- **description傾向**: 楽器数を絞り、碧衣の囁くような歌声と空気感を重視したミニマルな構成。余白と静寂が感情を語る。
- **参考サンプル**: サンプル8

### パッケージC：躍動（J-Pop / Electronic）

- **適応**: 新しい挑戦、晴れやかな出発、旅の楽しさ。

## 5. 彩り軸（曲調の可変要素と抽選）

スタイルパッケージ（セクション4）が曲の「系統」を決めるのに対し、彩り軸は同じパッケージが選ばれた週でも曲の表情を変えるための可変要素です。画像生成ガイドラインの構図4軸（`image_guideline.md` セクション8③）と同じ方式で、**作者の自己選択による曲調の偏り（暗黙の定番への収束）を `random_choice` の抽選で機械的に打ち消す**ことを目的とします。どの語彙にも固有の効果があり、構造的に避けるべき選択肢はありません。

### 5-1. 抽選軸（`random_choice` で抽選する2軸）

パッケージ決定後、以下の2軸は語彙表から **`random_choice` スキルで抽選**してください。今回のインスピレーションが特定の曲調を必然的に要求する場合を除き、自分では選ばないことが原則です。抽選結果がシーンとどうしても噛み合わない場合のみ、その理由を踏まえて選び直して構いません。

#### テンポ感

- **スローバラード（slow ballad）**: 言葉の一つずつを聴かせる。余韻と静けさ、夜や雨の内省と好相性
- **ミッドテンポ（mid-tempo）**: 歩くような等身大の推進力。日常や旅路の速度感
- **アップテンポ（uptempo）**: 躍動と高揚。景色が流れていく疾走感、出発や晴天の解放感
- **緩急型（dynamic tempo shift）**: 静から動へ、曲中で熱量が動く。物語の起伏を構成そのもので語る

#### ボーカル表現（description の [Vocal Style] に反映）

- **囁くように（whispery, intimate）**: 耳元で語る親密さ。静かなアレンジで最も生きる
- **息づかいを残して（breathy, delicate）**: 儚さと透明感。感情の機微を伝える
- **伸びやかに（soaring, expansive）**: サビで空へ抜ける解放感。壮大な曲調の推進役
- **芯のある力強さ（powerful, resolute）**: 決意・達成の主題を支える。静かな曲でも芯として機能する
- **語りかけるように（conversational, soft）**: 手紙のような等身大の距離感。聴き手に寄り添う

いずれも固定要素 `Lead Vocal (Female, Clear, Japanese)` と両立します（基本声質に加える感情的形容詞として使います）。

### 5-2. 自由選択軸（シーンに合わせて選ぶ3軸）

以下の3軸は、パッケージ・抽選結果・週の空気に合わせて自由に選択して構いません。ただし「気づくと毎回同じ」になりやすい軸のため、選択が偏っている自覚があるときは `random_choice` の活用を推奨します。

#### 曲構成の型

- **イントロの入り方**: ピアノソロ（核の提示・内省的） / パッドや環境音の霧から（空気感の醸成） / ボーカル先行（言葉を最初に届ける） / リズム先行（躍動の予感）
- **ブリッジ（Cメロ）**: あり（視点の転換・感情の深化を挟む） / なし（反復の心地よさと没入）
- **アウトロの型**: 余韻フェード（残響が消えていく） / 静かな収束（楽器が一つずつ減り、核だけが残る） / 冒頭モチーフの再現（円環の物語性）

#### 明暗

- **メジャー寄り（明）**: 晴れやかさ・感謝・出発の空気
- **マイナー寄り（陰）**: 感傷・憧憬・雨や霧の心象
- **明暗の往復**: 陰から光へ（あるいはその逆へ）と移ろう。一週間の起伏をそのまま感情の弧にする

#### 英語フレーズの混在率（歌詞側の軸）

- **日本語のみ**: 言葉の純度を保つ。和風・静謐な曲調と好相性
- **サビの短い英語フレーズ**: サビの開放感を後押しする（1〜2フレーズ程度）
- **英単語の点在**: 質感として軽やかさを添える（乗せすぎない）

この軸のみ楽曲プロンプトではなく歌詞に反映します（`modes/song.md` ステップ2の下書き、およびステップ4の最適化プロンプトの【曲の概要】で言語の方針として言及してよい）。

### 5-3. 反映先

抽選・選択した彩り軸は、次のように反映してください。

- **テンポ感・明暗** → `tags`（例: `Uptempo`, `Melancholic`）と `description` の全体トーン
- **ボーカル表現** → `description` の [Vocal Style]（基本声質に加える感情的形容詞）
- **曲構成の型** → `description` の [Intro] / [Outro]。ブリッジの有無は展開の記述に織り込む
- **英語フレーズの混在率** → 歌詞の下書き・最適化（楽曲プロンプトには含めない）

## 6. Descriptionの記述テンプレート

Descriptionを記述する際は、以下の流れ（弧）を意識して英語で5〜8文程度にまとめてください。

1. **[Intro]**: 碧衣の「核」であるピアノやパッドから始まる、静かな導入（セクション5-2「イントロの入り方」の選択結果に応じて変えてよい）。
2. **[Verse]**: 1週間の出来事を振り返るような、抑えめの展開。
3. **[Chorus]**: パッケージに応じた感情の昂ぶり（壮大さ、あるいは深い沈潜）。
4. **[Vocal Style]**: 碧衣の基本の声質に、「優しく」「力強く」などの感情的な形容詞を1つ加える（セクション5-1「ボーカル表現」の抽選結果を反映する）。
5. **[Outro]**: 尾羽の星が瞬くような、繊細な余韻（セクション5-2「アウトロの型」の選択結果を反映する）。
