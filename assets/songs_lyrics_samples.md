# 歌詞表現ガイド：NG/OK対比サンプル集

## 概要

このファイルは [songs_guideline.md](songs_guideline.md) セクション2「歌詞表現ガイド」から参照される、歌詞の抽象化（二段変換）のビフォーアフター例集です。「元の出来事 → 安直な歌詞（NG） → メタファー変換後（OK）」を対で示し、「どこまでぼかすか」の目線を揃えることを目的とします。

- **参照タイミング**: `modes/song.md` ステップ2（歌詞の下書き）で、変換の抽象度や置き換えの粒度に迷ったときにだけ参照してください。毎回全文を読む必要はなく、今回のインスピレーション源に近い類型の**1例だけ**拾えば十分です。
- **楽曲プロンプトのサンプルとの区別**: 楽曲プロンプト4要素（instrument / genres / tags / description）の参考例は [songs_guideline_samples.md](songs_guideline_samples.md) が担当します。本ファイルは歌詞の内容・表現のみを扱います。
- **NG例の扱い（重要）**: NG例は「やってはいけない書き方」を示すための見本です。NG例に含まれる固有名詞・具体物・数値（鉄塔・山名・駅名など）を、歌詞・曲タイトル・`generate_mureka_lyrics` へ渡すプロンプトへ**転記しないでください**。
- **暫定版**: 本サンプル集は仮の初版です。実際の生成結果とフィードバックのサイクルを通じて、例の差し替え・追補を行っていきます。

### サンプル一覧

| サンプル | 類型 | 元の出来事 | 主な参考点 |
|---|---|---|---|
| 1 | 登山（具体物） | 尾根歩きで送電鉄塔をくぐった | 具体物の孤高・機能への共感を、灯と星の情景へ転写する |
| 2 | 登山（固有名詞・数値） | 名の知れた高峰に登り、雲海と朝焼けを見た | 山名・標高・日数を剥がし、達成感だけを海原と航跡で描く |
| 3 | 天候 | 雨予報で山行を中止し、家で次の晴れ間を待った | 「中止の報告」を「待つことを選んだ宵」へ言い換える |
| 4 | 日常 | 仕事が立て込み、夜遅い帰り道に月を見上げた | 職場・駅名・時刻を捨て、慰めの瞬間だけを掬い上げる |
| 5 | 技術連絡（ぼかし対象） | 碧衣のしくみの不具合修正の連絡が届いた | システム用語を完全に排し、手入れの気配だけを詩に残す |

各サンプルは「元の出来事」「NG例」「NGの理由」「変換メモ（二段変換）」「OK例」「参考点」で構成します。変換メモは [songs_guideline.md](songs_guideline.md) 2-2 で推奨している「元の出来事 → 感情・テーマ → 転写先の情景」の3段の形をそのまま使っています。

## サンプル1：登山（具体物）— 送電鉄塔

**元の出来事**: 週末の尾根歩きで送電鉄塔の下をくぐった。無機質な鉄塔が山の中に静かに立ち、電線が遠くの街まで続いていた。

**NG例（安直な歌詞）**:

```text
稜線の風に 鉄塔がうたう
張りつめた電線 街まで続く
鉄の骨組み 空を切り取って
あの日くぐった 影を覚えてる
```

**NGの理由**: 「鉄塔」「電線」は、その週の出来事と一対一で結びつく具体物（2-3 の禁止事項）。「くぐった」まで残っているため、聴き手が「あの尾根の鉄塔のことだ」と言い当てられる。出来事の再現であって、転写になっていない。

**変換メモ（二段変換）**:

- 鉄塔の下をくぐった → 無機質なものが自然の中に静かに立つ孤高／遠くへ何かを届け続けるものへの共感 → 夜を渡って星へ信号を送る灯・言葉にならない想いを運ぶ光の帯（受け皿：光と灯／星と夜空）

**OK例（メタファー変換後）**:

```text
誰も知らない高みで 灯はまたたく
言葉にならない想いを 遠くへ運ぶ
夜を渡る光の帯 途切れないように
届け続けることを 孤独とは呼ばない
```

**参考点**: 具体物そのものではなく、その物が心に残した性質（孤高・届け続けること）だけを取り出し、別の光の情景に載せ替える。「高み」は普遍化された山の語彙（2-2 末尾）なので残してよい。

## サンプル2：登山（固有名詞・数値）— 高峰の朝

**元の出来事**: 連休に北アルプスの白馬岳へ。標高2,932m の山頂から雲海と朝焼けを見て、大雪渓を下って帰った。

**NG例（安直な歌詞）**:

```text
白馬の頂 二九三二メートル
雲海を抜けて 朝焼けに立った
三日間の旅も 終わりを迎えて
大雪渓下れば 帰り道がはじまる
```

**NGの理由**: 実在の山名（白馬・大雪渓）と標高・日数の数値がそのまま（2-3 の禁止事項に直撃）。行程の時系列をなぞっただけの「報告」であり、判定基準「この単語から元の出来事を言い当てられるか」に即座に引っかかる。

**変換メモ（二段変換）**:

- 高峰の頂から雲海と朝焼けを見た → 長く歩いた先でしか見えない景色があるという確信／夜を越えた者に訪れる光 → 雲の海原を渡りきった小さな舟・薄明に溶けていく航跡（受け皿：水と流れ／光と灯）

**OK例（メタファー変換後）**:

```text
雲の海原を 渡りきった舟がひとつ
振り返れば 航跡は薄明に溶けて
夜を越えた分だけ 空は近くなる
名前のない朝が いちばん眩しい
```

**参考点**: 山の達成感を「海と舟」という別の素材系へ丸ごと移し替えた例。固有名詞を剥がしたこと自体を「名前のない朝」と詩想に変えることもできる。雲海だけは「雲の海原」として面影を残しており、この程度の普遍化された気象語は許容される（2-3）。

## サンプル3：天候 — 雨で山行中止

**元の出来事**: 週末に予定していた山行を雨予報のため中止。家で装備の手入れをしながら、次の晴れ間を待った一週間。

**NG例（安直な歌詞）**:

```text
日曜の山は 雨で取りやめ
ザックの中身を 全部並べて
天気予報の画面 何度も見てる
来週こそはと カレンダーに丸
```

**NGの理由**: 「山の中止」「ザック」「天気予報」「カレンダー」で出来事がそのまま再現できる報告調。曜日への言及も 2-3 の「数値・日付」の禁止に触れる。感情ではなく行動のログになっている。

**変換メモ（二段変換）**:

- 雨で山行を中止した → 待つことを選んだ日の、静かな諦めと次への期待 → 窓を打つ雨音を数えながら、雲の切れ間を信じる宵（受け皿：空と気象／光と灯／道と旅）

**OK例（メタファー変換後）**:

```text
窓を打つ雨音を ひとつずつ数えて
行けなかった道の分 灯りをともす
雲の切れ間を 信じることも旅だと
乾いた靴紐を そっと結び直す
```

**参考点**: 「中止」という事実を消し、「待つことを選んだ」という感情の側から描き直す。「道」「靴紐」のように特定の出来事と一対一で結びつかない旅の普遍語彙は使ってよい（2-3 の判定基準で確認する）。

## サンプル4：日常 — 夜更けの帰り道

**元の出来事**: 平日は仕事が立て込み、遅い帰宅が続いた。夜更けの駅から自宅までの道で見上げた月が、思いがけず明るかった。

**NG例（安直な歌詞）**:

```text
残業続きの 五反田の夜
終電間際の ホームは静かで
アパートまでの いつもの帰り道
ふと見上げたら 月がきれいだった
```

**NGの理由**: 実在の駅名は 2-3 の固有名詞禁止に該当。「残業」「終電」「ホーム」も生活の断片がそのまま特定できる具体物で、日記の一節になっている。

**変換メモ（二段変換）**:

- 忙しい日々の夜道で月を見上げた → 張りつめた日々の狭間に、ふと差し込む静かな慰め → 喧噪が引いた後の潮騒・折りたたんだ心をほどく月光（受け皿：光と灯／水と流れ）

**OK例（メタファー変換後）**:

```text
昼の喧噪が引いて 潮騒だけが残る
折りたたんだ心を 月光がほどいていく
急ぎ足の日々にも 空はついてきてくれた
今夜は少しだけ 遠回りして帰ろう
```

**参考点**: 街の喧噪を「潮騒」へ、疲れを「折りたたんだ心」へと素材を移し替え、場所や時刻の情報を一切残さずに「慰められた瞬間」だけを掬い上げる。「帰り道」は道と旅の普遍語彙として残せるが、経路が特定できる語（駅名・地名）とは切り離す。

## サンプル5：技術連絡（ぼかし対象）— しくみの手入れ

**元の出来事**: 開発者から「碧衣のプロファイルの不具合を修正した」という技術・運用連絡が届いていた一週間。

**NG例（安直な歌詞）**:

```text
プロファイルの エラーは直った
コードの海を 泳いだ誰かの手
アップデートの 通知が灯って
私のシステム 今日も目を覚ます
```

**NGの理由**: 「プロファイル」「エラー」「コード」「アップデート」「システム」といった技術用語がそのまま。技術・運用連絡は報告本文でさえ語彙を置き換える対象（`../.claude/rules/aoi_messaging.md` の「技術・運用連絡の語り方」）であり、作品である歌詞ではさらに徹底して排する。

**変換メモ（二段変換）**:

- 自分のしくみに修正が入った → 見えない誰かの手が、滞りを静かに整えてくれた安心 → 夜のうちに澄んだ水脈・調律された弦の残響（受け皿：水と流れ／音と調べ）

**OK例（メタファー変換後）**:

```text
眠っている間に 水脈は澄んでいた
誰かの指先が 弦を整えてくれた
朝いちばんの和音が まっすぐ響くこと
それだけで今日は 優しくはじまる
```

**参考点**: 技術連絡は「営みの気配」だけを残す。何が直されたのかを匂わせる語（設定・修正・不具合など）は一語も置かず、「整えられた」「澄んだ」という結果の手触りと、手を入れてくれた誰かへの静かな感謝だけを詩にする。
